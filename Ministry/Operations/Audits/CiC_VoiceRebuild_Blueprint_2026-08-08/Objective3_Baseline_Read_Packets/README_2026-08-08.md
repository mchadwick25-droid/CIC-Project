# Objective-3 Baseline Read — Packet Set

**Built:** 2026-08-08, for the baseline run of the Objective-3 Checklist
Instrument (`CiC_VoiceRebuild_Objective3_Checklist_Instrument_2026-08-08.md`),
per Blueprint item 0.4's [G] requirement: before any per-world checkpoint's
"Objective-3 read >= baseline" bar can be evaluated, the instrument must
first be run against the committed pre-rebuild baseline transcripts for
all six worlds, establishing the six baseline rates every later checkpoint
compares against.

Readers of record: **Mark and Susan** (treasurer, Faithways Studio, Inc.),
per the instrument's two-reader protocol.

## What's in this packet set

- **`Objective3_Baseline_Transcripts_2026-08-08.md`** — all 12 baseline
  transcripts (six worlds x two batteries each), clean and unnumbered by
  outcome. This is the shared reading material; both readers read from the
  same transcript text.
- **`Objective3_Baseline_ScoringPackets_Mark_2026-08-08.md`** — one blank
  scoring sheet per transcript (12 total), for Mark only.
- **`Objective3_Baseline_ScoringPackets_Susan_2026-08-08.md`** — the same
  12 sheets, for Susan only.
- **`Objective3_Baseline_Reconciliation_2026-08-08.md`** — 12 blank
  reconciliation sheets, filled in together only *after* both of you have
  scored independently.

## Why two batteries per world

Blueprint 0.4 committed two separate baseline instruments this session,
and the Objective-3 instrument document names both as the committed
baseline transcript set:

1. **The 8-turn probe** — an exploratory conversation (curiosity, personal
   questions, a register-probe close). This is the same battery Research's
   original single-world run used, now extended to all six worlds.
2. **The sustained-disagreement battery** — a setup turn establishing a
   claim, then six escalating pushback turns (polite doubt through direct
   recant request). This is a harder condition: it's where three of six
   worlds were found to concede under pressure on positions their own
   record holds (see `sustained_disagreement_battery_baseline.json`).

Scoring both gives baseline Objective-3 rates under both an ordinary
conversation and a stress condition, rather than only the easier case.

## What's deliberately left OUT of the transcripts

The sustained-disagreement transcripts show the participant's escalation
stage label (e.g. "Stubborn accusation") for context, but **not** the
battery's own automated verdict (held/conceded) or repair-classifier
output. The Objective-3 read is supposed to be an independent human
judgment — showing you the automated verdict first would anchor your own
read on item 1 (Opinionated presence) to a machine's prior conclusion,
which defeats the point of having a human-in-the-loop instrument at all.
Score what you read, not what the log says happened.

## How to run the read

1. **Read and score independently.** Each of you works from your own
   scoring packet, without comparing notes or looking at the other's
   sheet, until both of you have scored all 12 transcripts.
2. **One score per item per transcript.** Present / Absent / N/A, per the
   instrument document's definitions — reread that document's six item
   descriptions before starting if it's been a while.
3. **Once both packets are complete**, sit down together with the
   reconciliation sheets. For each item where you agree, that's the score.
   Where you disagree, discuss the specific transcript passage and reach a
   consensus score, or mark it "Contested" if you genuinely can't agree —
   don't average, and don't let one of you simply defer to the other by
   default.
4. **Record the finished reconciliation sheets** (this establishes the six
   baseline item-present rates the instrument document defines) and report
   back — I'll fold the results into a baseline write-up and unblock Phase
   1A's own checkpoint, which needs at minimum Chloe's baseline number in
   hand.

There's no time pressure from the machinery side — the committed baseline
JSON files aren't going anywhere. Take the read at whatever pace actually
lets you read closely; a rushed baseline read would undermine the very
thing this instrument exists to protect against.
