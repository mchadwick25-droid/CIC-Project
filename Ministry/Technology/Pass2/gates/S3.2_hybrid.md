# S3.2 checkpoint — G (hybrid BM25+RRF + R8 expansion; verbatim-term is the win condition)

**Step:** S3.2 — Pass 1 R3 + R8. **Date:** 2026-07-27.

## The change

- `app/rag/hybrid.py` (new): BM25 over a **field-boosted lexical corpus**
  (term/aliases/story-title x3 + retrieve-when + quick-meaning; the
  Related line deliberately excluded) fused with dense FAISS by weighted
  RRF (dense 1.0 / lexical 0.7, k=60); R8 one-hop related-terms expansion
  from the fused top-k, entering at expansion rank (never displacing a
  direct hit). Deterministic, CPU-only, no API calls.
- Retrievers gain `candidate_search()`; `retrieve()` and the eval
  harness's `replay()` both route through it — the harness measures the
  real pipeline (same (doc, score) contract; the harness edit is the
  minimal instrument extension, behavior-identical for a dense-only
  retriever).
- `rank-bm25` added to requirements (nothing supplied lexical search
  before — the Touches verification's "genuinely new dependency").

## Three real defects found by the harness during the build (fixed before commit)

1. ASCII-only tokenization shattered macron transliterations
   (anachōrēsis → anach/r/sis) — the exact lexical path R3 exists for;
   fixed with NFD diacritic folding.
2. Related-terms lists flattened every term name's idf (the exact term's
   own doc lost the lexical race on "What is theosis?" to docs merely
   *related* to it) — fixed by excluding Related from the lexical corpus
   and boosting identity fields.
3. rank_bm25's epsilon flooring keeps near-universal tokens positively
   scored, so stopword mass swamped the discriminating token ("…speak of
   the Logos?" top-ranked docs containing no 'logos' at all) — fixed
   with per-corpus df-based query stopwording (df > 50% dropped).

## G — the win condition and the delta (committed: `baselines/retrieval_post_S3.2.json`)

- **verbatim-term mean MRR = 1.0 in all six worlds** — including
  Imperial-Juridical, which was 0.8333 at B-RETR: the hybrid beat the
  pre-S3.1 baseline, not just recovered it. PAHC and Alexandria verbatim
  fully restored from the S3.1 dip.
- vs B-RETR overall: **24 improvements, 13 regressions**. Every residual
  regression sits in a class a later Phase-3 step owns by design:
  reactive-turn (Alexandria/Desert/HAL) is the R9
  other-world's-turn-drives-the-search failure S3.5's query rewriting
  replaces (the rewritten standalone query for the failing case would hit
  theosis's own aliases directly); negative-condition violations
  (HAL/PAHC/Syriac, +1–2 each) are S3.3/S3.4's exclusion-set and
  cross-encoder territory; one Alexandria thematic recall cell (−0.08).
- Carried forward: those cases are S3.5's (reactive-turn) and
  S3.3/S3.4's (negative-condition) named recovery targets.
