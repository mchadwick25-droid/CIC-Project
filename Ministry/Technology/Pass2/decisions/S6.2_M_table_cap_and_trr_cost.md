representatives at a table at 3, 5 costs too much to run" — given
while stopping the IJC hal-table TRR re-run.

## What this decides

1. **The 3-representative table cap is CONFIRMED AS STANDING POLICY**
   (it already exists in code: `app/main.py` caps `world_ids[:3]`,
   "Prototype/Phase 1 scope - cost and complexity"). No code change
   needed; the cap is now Mark-ratified policy, not just a prototype
   note.
2. **Close-out TRR practice is COST-CAPPED:** the per-freeze TRR does
   NOT scale one-table-per-frozen-partner as the fleet grows. The
   IJC round ran five two-representative tables (Marius + one
   partner each — table size was never above 2); the cost driver was
   table COUNT. Future close-outs (and any re-runs) sample the
   partner set rather than exhausting it.
3. **The IJC hal-table re-run is STOPPED by this decision.** The
   freeze proceeds on the evidence in hand: the truncated first
   run's four valid turns — which covered the round's sharpest
   presses (the Jerome-served-Damasus adjacency refusal at turn 2;
   both-memories-of-Damasus held apart; the settle-it refused at
   turn 4) — with turns 5-8 (the women's-standing cross, own-tongue,
   name-your-divergence) recorded as NOT RUN by cost decision, a
   declared evidence limit in the gate report and declaration, not a
   silent gap.
