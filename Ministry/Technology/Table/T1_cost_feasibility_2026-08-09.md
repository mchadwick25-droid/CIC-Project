# T1 — Can a 3-Representative Table be run at a price the program can pay?

**Phase 1 of the multi-Representative table thread. Analysis only — no code
was touched.** Every dollar figure below is generated by
`Ministry/Technology/Table/t1_table_cost_model.py`, which re-prices the
committed B-COST raw log with the runner's own pricing and refuses to run
unless it reproduces the report's total ($3.3924 / 689 calls) exactly.
Tags: [M] measured, [E] estimated from measured token shapes, [S]
speculative. Standard Sonnet/Haiku pricing throughout — the intro pricing
that ends 2026-08-31 is not a planning basis.

**The answer, up front.** The table cannot reach free-tier economics
(~$1/user/month, the number the live ask copy is built on) without ceasing
to be a real table — that is the honest floor, stated in §5. But the table
was never a free-tier feature: it is decided paid-tier (2026-07-31, SH-12
scope). Priced against a paid subscriber instead of the free-tier anchor,
a real 3-Representative table is affordable today and comfortably
affordable after two changes that need no product trade-off at all. The
$5/hour Mark refused to pay is real at the current shape ($4.73/hr
measured, fast pacing); the target architecture lands at **$0.135/round ≈
$3.25/hr fast / $1.35/hr contemplative**, and a heavy user (a weekly
one-hour sitting) costs **$9–14/month** — covered with margin by a
$15–19/month tier, roughly break-even at the already-anchored $8/month
supporter level.

## 1. Corrections to the measured record (found while reconciling)

These change numbers the thread brief carries; they are stated first so
nothing downstream inherits them silently.

1. **The honest table turn is $0.1971, not $0.1585.** [M] The report's
   C4 per-turn average divides by 10 turns, but turns 9–10 are
   conversation-cap turns that streamed a canned message with zero LLM
   calls. The 8 real rounds cost $1.5767 → **$0.1971/round, 3.10× solo**
   ($0.0636, same slice). The brief's "31 turns ≈ $4.91" becomes "25
   rounds ≈ $4.93" — the $5/hour figure survives the correction; it is
   real either way.
2. **The run notes' "≈$0.38/turn uncapped" headline is an arithmetic
   slip, roughly 2× high.** The raw log's `input_tokens` *includes* cache
   tokens; billing them again at the full input rate doubles the number.
   The runner's report does this correctly; run-notes item 1 ($0.307 /
   ≈$0.38) does not. I made the identical error on first pass and caught
   it only because the model refuses to run without reconciling — that
   reconciliation gate is now committed in the T1 model.
3. **"All three Representatives speak every turn" is not what the code
   does, and 2.8 generations/turn overstates the round shape.** [M] The
   28 main_response calls are 21 representative turns + 7 hard-ceiling
   retries: **2.62 rep turns per round**, produced by a selector
   (`select_next_speaker`) that already implements "most directly
   positioned, not rotation" (FG §8), with a floor of 2
   (`wrs/parameters.yaml turn_floor_multi_world`) and a max of 6.
4. **Pass 3's #1 open question is answered in the report's own data.**
   The 2026-07-30 cost-floor model flagged table regeneration as
   unmeasurable and "plausibly 30–60% of Table generation cost." The
   report's `split_retry_calls` reconstruction settles it: 7 retries,
   $0.1765 = **18.9% of table generation, 11.2% of the table turn** [M] —
   real money, not the catastrophe feared.
5. **The baseline is stale in both directions, and the errors roughly
   cancel.** Landed since 2026-07-26: S3.4 removed the LLM relevance vote
   (the measured $0.0337/round retrieval-filter line shrinks to a
   guard-only call, −$0.011/rep-turn [E]); S4.4a skips selector calls on
   addressed turns (−). But S4.6/S4.7 added a governance tail the
   baseline never saw — repair classifier, register classification,
   misattribution / manufactured-resolution / closing-synthesis /
   convergence checks, citation grounding — **+~$0.016/round +
   $0.0025/rep-turn [E]**. Net ≈ zero. Only the post-swap re-measure
   (§7) gives the current number.

## 2. The cost architecture

One structural fact organizes everything:

**cost per participant round = FIXED + (rep turns per round) × MARGINAL**

Measured [M], per the committed log:

| component | $ | notes |
|---|---|---|
| MARGINAL — generation (Sonnet draft) | 0.0361 | 51% of the marginal dollar |
| MARGINAL — ceiling-retry overhead | 0.0084 | desert-heavy seating; 33% fire rate |
| MARGINAL — retrieval filter | 0.0128 | mostly gone in current code (S3.4) |
| MARGINAL — per-rep governance (drift, over-settling, fabrication) | 0.0115 | |
| MARGINAL — turn selector | 0.0025 | |
| **MARGINAL total** | **0.0714** | per representative turn |
| FIXED — per-message governance (frame-breaker, relational safety, epistemology, modern-term, wind-down) | 0.0072 | per round |
| FIXED — round-end selector call | 0.0025 | |
| **FIXED total** | **0.0097** | |

Check: 0.0097 + 2.62 × 0.0714 = $0.1970 against $0.1971 measured.

What this shape means: **the round-shape multiplier is the only lever
that moves the whole dollar; everything else trims one term.** Prompt
trimming is confirmed dead as a lever — the static blocks are cached
(output is ~24% of a generation's cost, uncached input dominates, and the
cached prefix reads at 0.1×). The Haiku swarm (24 of 27 calls) is 41% of
spend combined; no single Haiku line is worth more than ~$0.016/round.

## 3. The levers, each priced with its quality cost

**L1 — Round shape (THE lever).** Each rep turn avoided saves the full
marginal (~$0.055 after L2/L3). The brief asks this not be resolved by
assertion, and it isn't resolvable from this log: the fixed set's C4 is
one scripted conversation whose questions skew comparative ("what do each
of you think" shapes). What the code already believes is on the record —
FG §8's "most directly positioned, not rotation, not equal time," a
selector that may return NONE, direct-address routing that ends a round
after one addressed answer. The lever is therefore not a new constraint
but *enforcing the economics of the principle the table already holds*:
either cap `MAX_MULTI_WORLD_TURNS` at 2 (round = one real answer + one
real response; $0.135/round [E]) or drop the floor to 1 and let the
selector end rounds honestly (~1.6 avg → $0.113/round [E/S], "one voice
answers, others enter when they genuinely differ").
*Quality cost:* fewer voices heard per round — but a third voice can
always be drawn in next round, and the selector's own design says a
question fanning out to every world "flattens into a panel." The genuine
risk is the differ-detection failing silently: a world that should have
objected staying quiet. That is measurable (§7) and must be, before
either variant ships.

**L2 — Lossless fixes, no participant-visible change.** [E, medium-high
confidence] (a) The desert ceiling-retry fix — Pass 3's A3 move, the
numeric measure into the post-history guard slot — halves retry overhead:
−$0.004/rep-turn. (b) Over-settling adjudication scoped to once per round
(worst screen hit) instead of per rep turn: −$0.004/rep-turn. Together:
$0.197 → **$0.170/round at the current shape**.

**L3 — Retrieval sharing: already landed, do not re-do it.** The brief's
"11.3 Haiku filter calls, most obviously shareable" describes code that
no longer exists — S3.4 replaced the relevance vote with a local
cross-encoder; the surviving guard-only call fires only when a
relevance-kept candidate carries an evaluable Do-Not-Retrieve-When, which
after the five world swaps land will be rare (migrated worlds' chunks no
longer carry the retired clauses). Nothing to build; one thing to
verify at re-measure. The interference rule is moot here in the best way.

**L4 — Model tiering.** [S] A generation on Haiku is $0.012 vs $0.036 on
the measured token shape. All-Haiku generation is the only lever that
reaches the free-tier band ($1.14/hr, Pass 3) — and Pass 3's caution
stands in full: the representative prompts are dense negative-constraint
instruction-following (55 prohibitive constructions, 7 WRONG/RIGHT
pairs), exactly the axis where a smaller model degrades first, and every
detector that would catch a tier failure is post-hoc. The bounded
variant — reactive turns only on Haiku, opening voice stays Sonnet —
saves $0.024/round at a 2.0 shape ($0.111/round). *Quality cost:
unmeasured and plausibly severe against the 1A bar the rebuild just
paid for. Not adoptable blind; cheap to settle with a blind-graded
battery (needs a live key only). Decision for Mark, after measurement.*

**L5 — Pacing.** Not a code lever, but the largest single multiplier on
$/hour: 24 rounds/hr (the investigation's pacing) vs 10 (contemplative
reading of 2–3 voices) is a 2.4× difference in hourly cost. Real table
pacing is unmeasured. The first weeks of live table traffic answer it
for free from existing logs.

**L6 — Prepared answers (SH-11): not a table lever.** Its own analysis
caps served traffic at ~5.2%, Table mode is excluded by design, and the
table bank is the expensive one to build. Confirmed dead for Phase 1.

**L7 — Pricing structure: the mechanism that actually closes the gap.**
See §6.

## 4. The architectures

$/hour at 24 / 16 / 10 rounds per hour (standard pricing):

| architecture | $/round | 24/hr | 16/hr | 10/hr |
|---|---|---|---|---|
| A0 measured baseline [M] | 0.1971 | 4.73 | 3.15 | 1.97 |
| A1 current code, pre-remeasure [E] | 0.1912 | 4.59 | 3.06 | 1.91 |
| A2 + lossless fixes (L2) [E] | 0.1696 | 4.07 | 2.71 | 1.70 |
| **A3 = A2 at 2.0 rep turns/round [E]** | **0.1354** | **3.25** | **2.17** | **1.35** |
| A4 = A2 at 1.6 (selector-honest) [E/S] | 0.1134 | 2.72 | 1.81 | 1.13 |
| A5 = A3, reactive turns on Haiku [S] | 0.1113 | 2.67 | 1.78 | 1.11 |

**Recommended target: A3 — $0.135/round.** It requires nothing
unmeasured: two lossless fixes plus a max-2 round cap on a principle the
governance already states. A4 and A5 are real but each carries a quality
question that must be measured first (§7).

## 5. The honest floor

**A real 3-Representative table with Sonnet voices cannot be run below
≈$0.11/round** (A4: full safety stack, honest selector, two voices per
round average). At measured fast pacing that is ~$2.70/hour; at
contemplative pacing ~$1.10/hour. Below that number, every remaining
dollar is one of three things the table cannot lose and stay itself:
the second voice (drop to 1.0 rep turns/round and it is a solo interview
with spectators), the Sonnet voice (the 1A fidelity the entire Voice
Rebuild just bought), or the safety/governance stack (relational safety,
drift, over-settling — non-negotiable for this program). **If the bar is
free-tier economics — the ~$1/user/month the ask copy anchors on — the
table cannot be done, and no design phase should be spent trying.**

## 6. Affordability verdict — the number for Mark to accept or reject

The right denominator is not the free tier's $1/user/month; it is the
paid subscriber the 2026-07-31 decision already created. At A3:

- **A heavy user — weekly one-hour sitting — costs $9–14/month** ($9.31
  at 16 rounds/hr, $13.97 at 24). Worst-case single sitting is bounded by
  the existing 100-rep-turn cap at **≈$6.80**.
- A **$15–19/month** Table tier covers the heavy user with real margin.
  The already-anchored **$8/month** supporter level covers ~2–3 table
  hours/month — break-even for a moderate user, underwater for a heavy one.
- The free tier stays what it is: solo interview at $0.064/turn, $2.55
  worst-case conversation, consistent with the existing anchor.

**Proposed acceptance criterion for Phase 1: the table is feasible at
$0.135/round (A3), paid-tier-only, priced at or above ~$15/month for
unmetered weekly use** (or $8/month with a soft monthly-hours
expectation). If that price point is unacceptable for the people Mark
wants at a table, the honest alternatives are metering (per-sitting
pricing against the ~$6.80 bound) or the A5 measurement — not a cheaper
architecture that silently stops being a table.

## 7. What Phase 1 hands to the gate (measurements, not designs)

1. **Re-run `scripts/cost_baseline_runner.py --run` after the five world
   swaps land and PR #9 merges** — same fixed conversation set, no edits
   to it — to replace A1's [E] with an [M]. This is the instrument the
   interference rule protects; nothing in Phase 1 touched it.
2. **Round-shape quality measurement (gates L1/A3-A4):** the existing
   8-turn probe battery is blind to table dynamics (the brief's own
   instrument-gap finding). Before Phase 2 designs anything, a
   conversational table probe set (models: `scripts/variance_probe.py`,
   `scripts/cross_world_probe.py`) must answer one question: with a
   2-turn round, does the voice that genuinely differs still get in —
   next round at the latest — or does difference silently vanish?
3. **A5 battery (only if Mark wants the number):** blind-graded
   Haiku-reactive-turns comparison, Pass 3's protocol. Needs a live key
   and nothing else.
4. **Live pacing measurement:** real rounds/hour from the first weeks of
   table traffic; it moves every $/hour figure in §4 and costs nothing.

**Not done here, by the phase gate:** no round-cap change, no
over-settling scoping, no retry fix, no table_discourse.py work, no
Phase 2 quality analysis. The five pending swaps and PR #9 were not
touched.
