## The strategy, in one paragraph

Church in Conversation stays fully free for anyone, forever — bounded only by usage time, never
by depth or rigor. It's funded primarily by people who've already had a real encounter choosing
to keep it open for the next person, plus paid tiers that buy more time and genuinely new tools
(never more truth), plus institutional licensing and mission-aligned sponsorship running in
parallel on their own slower relationship clock. Nothing is funded by debt, large personal cash
from Mark and Susan, or outside control. Faithways Studio stays the flexible parent so Church in
Conversation can either be handed on modestly or converted to a nonprofit later — whichever
serves the mission better when that choice actually needs to be made.

## The four boundaries this roadmap never crosses

No debt · no large personal cash outlays · no influence given away to anyone who wants it · no
IPO or venture-scale growth trajectory.

## Phase 1 — Go live (immediate, days not weeks)

**Program (dependency, Mark's own account-creation steps):**
- Render hosting account + Web Service pointed at `cic-poc/`
- `ANTHROPIC_API_KEY` + `CORS_ORIGINS` set
- Anthropic Console spending ceiling set (~$100–150 to start)
- The live site's "Launch a Conversation" button pointed at the hosted app

**Business:**
- Publish the keep-it-open gesture on `support.html` — direct Stripe, on-domain, no accounts.
  Suggested amounts market-validated this week: **$10 one-time / $8-month recurring.**
- **Still open:** final wording for the gesture itself — avoiding the tipping register was
  decided; the exact word ("keep the Table open," "Steward," or something else) wasn't.
- Write down the Organizational Covenant's "always-free core access" line — costs nothing, closes
  a long-open item, and is the natural anchor for everything else in this roadmap.

## Phase 2 — Learn (first several weeks of real traffic)

- Watch real conversion and usage against the market analysis's benchmark: **~2% of the free base
  is the honest planning number**, not the informal "2%" this project had been citing before
  (that number turned out to be Wikimedia banner copy, not a measured rate — corrected this week).
- Recalibrate the Anthropic spending ceiling against real data, not the pre-launch estimate.
- **The free-tier time cap is deliberately not being set from a projection — it gets set from
  real pilot data, on purpose.** Real cost testing this week ($1.25–1.50/hour of conversation)
  gives the method (budget ÷ rate ÷ target audience), but Mark and Susan's own call is to run the
  pilot first and let real numbers decide the actual figure, not lock it in ahead of evidence.
  What the pilot needs to surface to make that call well: real average conversation length per
  user, the real usage distribution (does the "spike then bifurcate" pattern — a big first
  encounter, then either real depth or drop-off — actually hold at real scale?), and real spend
  velocity against whatever ceiling is live.
- Send the refreshed Letter to Friends to Mark and Susan's own network — doesn't wait on web
  traffic at all, runs in parallel, fully within their own control.
- Begin relational conversations toward the Academic Advisory Circle — informal, no build
  dependency, can start the moment there's bandwidth.

## Phase 3 — Build the second rung (once Phase 2 shows real signal, not a fixed date)

- Build the subscription tier: more usage time, genuinely funds operating cost (not just the
  user's own API usage), plus the community/reflection layer.
- **Still open:** the actual number behind "capped" free time.
- Finish the case-for-support document — only the "Why Under a PBC Umbrella" section exists today;
  case summary, the model, proven history, and vision remain.
- Formalize the Academic Advisory Circle: who, how convened, whether/how compensated, first real
  review commissioned through it.
- Set a reserves policy — BibleProject's ~6-month-operating-expense discipline, scaled to CiC's
  own much smaller budget.
- Set the free-tier time cap for real, using Phase 2's actual pilot data — this is where the
  deliberately-deferred decision from Phase 2 gets made.

## Phase 4 — Deepen (once the subscription tier proves out)

- Build the role-tailored tier: pastor/teacher tools, academic tools (including the parked
  comparative-brief tool if it's still worth it by then), homeschool tools.
- Pursue institutional licensing through the Academic Advisory Circle's own relationships, not
  cold outreach — the circle is the actual engine here, not a side project.
- Access-broadening features as bandwidth allows: translation, sliding-scale pricing, low-
  bandwidth mode, public access points.
- Actively pursue donated/discounted compute (the Khan Academy lever) to extend the free tier's
  own runway without needing more revenue.

## Phase 5 — The structural choice point (later — a real trigger, not a calendar date)

- Revisit the fork the research surfaced: a modest continuity sale of Church in Conversation, or
  converting it to a nonprofit, are **mutually exclusive endings**, not both available at once.
  Faithways Studio's parent/product structure keeps both doors open until this choice is actually
  made — nothing forces the choice now.
- A golden-share or charter-provision mission safeguard only becomes relevant *if* outside equity
  is ever taken — not needed while Mark and Susan hold the stock together.

## What stays true across every phase

Rigor and sourcing are never for sale. Sponsorship confers honor, never influence. No single
institutional partner carries outsized weight or its appearance. Every pre-existing draft is
source material until reworked and confirmed. Prove each rung with real signal before building
the next one.
