# Front-End Integration Strategy

**What this is:** the architecture-level design work reconciling every designed/built
feature onto one coherent front-end — the three-tier disclosure vocabulary, the
numeric clutter budget per screen, and a conversation-primacy verdict for every
feature this project has designed (does it render inline, on demand, or not at all
during a conversation).

**Current state:** design complete through Engineering Specification V1.2. The
citation-UI half of Increment 1 is already built and verified conflict-free against
this strategy's own rules. Later, more visual/UX-specific work was absorbed into the
**Full-UX-Design/** feature folder rather than continuing here — see that folder for
the current screen-by-screen spec.

**Where deliverables live once integrated:** `cic-poc/frontend/`.

**Open items:** see `Decision-Log.md` for the current state of Increments 2-4 and
their dependency chain (role selection → Guided Questions UI → World Map merge).
