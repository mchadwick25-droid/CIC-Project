# Tour Experience Module (Phase Two)

**What this is:** an unbuilt Phase Two product concept — a broader "hosted
experience" mode design, distinct from and later-stage than `Hosted-Tour/`'s Phase
One built demo. Governs itself by the same evidentiary discipline as the rest of the
project: a tour is offered only where the sources actually support a communal-scene
reconstruction, and its absence for a thin world is treated as an honest finding, not
a gap to fill.

**Renamed from "Tour Experience Module" to add "-Phase2"** specifically to stop
colliding with `Hosted-Tour/` in prose and search — the two were referred to almost
interchangeably despite being different scopes.

**Current state:** planning artifact only (internally V0.3, despite the source
filename's `V0_1_DRAFT` — see its own Document Log). Nothing here touches `cic-poc`
code, the current prototype, or Phase One testing. Every build item is named as a
future handoff, not started.

**Where deliverables land once integrated:** not yet applicable — this is pre-build.
