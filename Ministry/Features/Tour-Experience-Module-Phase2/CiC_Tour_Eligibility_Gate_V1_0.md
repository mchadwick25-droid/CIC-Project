# TOUR ELIGIBILITY GATE

## Church in Conversation — Tour / Hosted Experience Module (Phase Two)

### Version 1.0

**What this is:** a repeatable, one-per-world procedure (Task Board TR-5) that
generalizes the per-world evidentiary-analysis method this project already ran once
by hand, across five worlds, in `CiC_Tour_Experience_Module_Strategy_V0_3.md` §3. Run
this **before** starting any Tour Manifest for a world — per that template's own Part
0, a manifest may only be authored for a world/scene this Gate has actually cleared.

**Not a new procedure invented for this document.** Every gate below is extracted
from, and cites, the specific real judgment the Strategy document's founding thread
actually made for one of its five worlds. Where the Gate generalizes beyond what any
single world's case demonstrated, that is flagged explicitly rather than presented as
already-tested.

**Governed by:** the Construction Framework's four-tier story classification and No
Tier 5 rule (the same bar Doc_09 itself uses); Constitution Article 17 (visible
confidence) and Article 19 (no free invention at any stage); the Strategy document's
Class A/Class B distinction (§2.2) and its per-world findings (§3.0–3.5).

**A word on "tier" — two different meanings, do not conflate them:**
**Evidentiary Tier** (1–4) is the Construction Framework's story-classification axis —
what Doc_09 already assigned to the anchor chunk. **Tour tier** (the Gate 7 verdict:
YES / QUALIFIED YES / PARTIAL / PARTIAL-THIN / NO TOUR) is this Gate's own output —
what *kind and completeness* of tour that evidentiary basis actually supports. A
Tier 1 evidentiary basis does not automatically mean a full worship-service tour; see
Gate 2.

## How to use this

Run Gates 0 through 7 in order, for one world at a time. Do not skip ahead — later
gates assume earlier findings (Gate 5's decline-stop work assumes Gate 2 has already
named which scene, if any, is the candidate, and at what depth it can be entered).
Record the answer to every gate **with a citation** to the world's own Doc_09, Doc_02,
Source Registry, or deployed Capsule/Permanent Prompt. An uncited "yes" or "no" is not
a completed gate — every real finding in the worked precedent below is a citation, not
an impression.

---

## Gate 0 — Does an approved Doc_09 exist for this world at all?

If no Story Inventory has been approved (build folder empty, or Doc_09 not yet Cleared
review), stop here.

**Verdict: NOT ASSESSABLE — NO TOUR.** This is not a finding about the eventual
world's evidence — it is a finding about the state of construction. Re-run this Gate
once Doc_09 is approved.

*Precedent:* Nicene-Cappadocian, Strategy §3.5 — build folder empty as of the analysis
date, no Doc_09, no capsule, no Representative. "This is not a finding about the
eventual world's evidence... that judgment belongs to its future Doc_02/Doc_09, not to
this document."

If Doc_09 exists and is approved, continue to Gate 1.

---

## Gate 1 — Does a real, sourced, COMMUNAL scene exist?

Search the world's approved Doc_09 Story Inventory — not the Permanent Prompt or
World Capsule Core alone, which may gesture at a practice without narrating an actual
event — for a story that is **both**:

**(a)** an actual narrated or liturgical description of an event, not a lexicon term,
not a doctrinal position, not a single passing mention; **and**

**(b)** a scene the participant could plausibly be *hosted through* as a shared,
communal experience — not an individual's specific biographical episode.

**(b) is the condition most easily missed, and it is not the same test as tier.** A
vivid, well-sourced, even Tier 1 individual story is not, by itself, a tour scene.

*Precedent for (b):* the Desert world's three Tier-1 founding scenes (Antony's call,
the staged withdrawal, Pachomius founding the koinōnia) are exactly this trap — "Tier
1 scenes told in full," and still ruled out as tour anchors: "they are individual,
specific-event narratives, not communal experiences a participant can be hosted
through... narrating Antony's call is already licensed conversational material; it is
not a tour in this module's sense, and stretching 'tour' to cover story-telling would
blur the module's own definition" (Strategy §3.3).

If no scene passes both (a) and (b): stop here. **Verdict: NO TOUR** — name the
absence plainly, with the specific reason (no communal scene at all, vs. communal
scenes exist but none are narrated). This is a complete, honest answer, not a
placeholder awaiting future content.

If a candidate scene passes both tests, continue to Gate 2.

---

## Gate 2 — Is the candidate a narrated description, or a thin mention?

This is the single most load-bearing distinction the whole method turns on, and the
one most likely to be skipped under time pressure. A **thin mention** — the shape and
the hour of a practice, sourced, but nothing of its interior — is not a tourable scene.
It is tourable only as far as its own threshold.

*Precedent, verbatim from a deployed World Capsule Core:* the Desert world's weekly
synaxis — "You can speak to its shape and its hour, not to its every phrase." Strategy
§3.3: "The synaxis itself is a thin mention, not a narrated description... A tour may
*walk to* the synaxis and say honestly what is and is not known of it; it may not
*enter and narrate* it."

- **If narrated description** → continue to Gate 3. The full scene may become a tour
  interior.
- **If thin mention only** → this scene supports, at most, an arrival-at-the-threshold
  beat that ends in an honest-silence stop (Gate 5). It does **not** support a full
  worship-service/communal-interior tour. Carry this finding forward explicitly into
  Gate 7 — do not let a later Tier label paper over the fact that Gate 2 already
  capped what kind of tour this scene can support. (This is precisely the
  distinction that produced the Desert world's PARTIAL verdict, and it is arguably
  "the single most formation-true moment this module could produce anywhere" when
  played honestly, per Strategy §3.3 — a thin mention, entered honestly, is not a
  lesser outcome to apologize for.)

## Gate 3 — What evidentiary Tier is the scene, and what does that make it?

- **Tier 1**, narrated in the source's own first-person or named-witness voice →
  **Class A** candidate — the tour's claim: "here is what one witness tells us, in his
  own words." Only one scene in the current five-world portfolio has ever qualified
  this way (`pahcstory006`).
- **Tier 4**, composite reconstruction, every element separately sourced, no named
  individual, no specific occasion → **Class B** candidate — the tour's claim: "a
  morning such as ours might keep."
- **Tier 2 or Tier 3** → **no live-portfolio precedent for this as a tour anchor.**
  Every Tier 2/3 narrative encountered in the actual per-world analysis (the Desert
  founding scenes) already failed at Gate 1(b) for being individual rather than
  communal. If a future world's evidence genuinely produces a communal, narrated Tier
  2 or Tier 3 scene, that is a real open architecture question — the Strategy document
  does not resolve it (its own §2.2: "the live worlds' tourable scenes fall into
  exactly two evidentiary shapes" is an empirical finding across five worlds, not
  necessarily a permanent rule). Flag it for the review cycle rather than force-fitting
  it into Class A or B.

## Gate 4 — What's the hardest constraint, and can it actually be honored?

Name every binding constraint the world's own record places on this scene. Check each
of the following, citing the world's own record for any that apply:

- **Geographic/temporal scope.** Is the scene bound to one place and time, and
  explicitly not generalizable beyond it? *Precedent:* PAHC's scene is Rome-only,
  "never generalized network-wide" (§3.1); Syriac's scene is bound to pre-363 Nisibis
  specifically — its calendar detail does not generalize even though its qyama/choir/
  hymn/Diatessaron elements do (§3.2).
- **Diversity-first.** Does this world's own approved record document more than one
  distinct version of this practice? If so, this tour must represent exactly one and
  must never blend them into a composite. *Precedent:* PAHC's three eucharistic
  practices (Justin's, the Didache's, Ignatius's) "are three practices, never one
  'early church service'" (§2.3, §3.1).
- **Representative-anchoring tension.** Does the world's deployed Representative carry
  a self-limiting line in their own Capsule/Permanent Prompt that appears to conflict
  with hosting this scene at length? *Precedent:* Mar Yausep's capsule says he speaks
  "only briefly of the gathering itself," in visible tension with `syrstory009` being
  an approved, extended, licensed scene (§3.2, item 3) — resolved by the standing rule
  "let the source make the call": the reviewed chunk's own license governs; the
  capsule's self-limit governs only *unscripted* expansion (§2.6). **If a comparable
  tension exists for the world under review, name it and route it to Mark — this is a
  live judgment about a world's own self-understanding, not a defect this Gate
  resolves on its own.**
- **Live-testing caution.** Is this the newest or least live-tested world in the
  portfolio? If so, note it as a sequencing caution (build/produce last), independent
  of the evidentiary finding itself. *Precedent:* Bethlehem Circle, §3.4.

## Gate 5 — Where does the evidence run out? (The Decline-Stop Point)

This gate determines the tour's required honest-decline stop (per the Tours rule,
front-end decision log, 2026-07-07, and modeled on Chloe's Stop 7, "What We Cannot
Show You"). For the qualifying scene, check each of the four things a participant most
wants from a hosted scene, and for each, determine whether the world's own record
actually *establishes*, or actually *forecloses*, an answer:

1. **What it looked like** (the room/setting).
2. **What was said** (the exact words of the core content — prayers, teaching, ritual
   speech).
3. **Who was there** (ordinary, non-famous named individuals).
4. **What it sounded like** (music, singing, ambient sound).

Every "we can't show you this" must be sourced as a **real, disclosed absence in the
world's own record** — never invented as a generic humility gesture, and never simply
"we haven't produced an asset for this yet."

*Worked precedents, one per category, each a model of exactly this check:*

- **The room:** PAHC's window is "essentially archaeologically invisible" (Doc_02 §5),
  and its two famous "early-church" visuals (Dura-Europos, the Abercius inscription)
  are **Excluded** Source Registry rows the world's own record refuses to borrow — a
  specific, sourced, checkable absence, not "we don't have art yet."
- **The words:** Justin's own text says thanksgiving is offered "according to his
  ability" — extempore; no fixed text ever existed to preserve. The absence is *in*
  the source, not around it.
- **The people:** exactly two ordinary members are named in PAHC's entire evidence
  base — Tavia, and the wife of Epitropus (Doc_09 §4, item 9) — a countable, checkable
  absence, not an impression.
- **The sound:** no musical notation survives from the Syriac world's window at all;
  nothing period-adjacent is usable either — Bardaisan's hymn texts survive mainly as
  fragments Ephrem quoted to refute them, with no music, and the nearest notated
  Christian music anywhere (the Oxyrhynchus hymn) is barred by the project's own
  cross-contamination discipline from standing in for this world's silence (§3.2 Sound
  findings). PAHC's own version of this: Pliny's report of pre-dawn singing is cited
  *with the cost its own usage guidance requires named* — the testimony was extracted
  by torturing two enslaved ministrae — rather than silently omitted.

If nothing about the scene actually runs out on this check — if the record appears to
answer all four categories fully — **treat that as a signal to check again more
carefully, not as a sign the record is unusually complete.** No world checked so far
has come up empty; a real ancient evidence base essentially never does.

## Gate 6 — Is any visual or audio asset actually licensed, or is this tour description-first by necessity?

Two independent findings — do not let a positive answer on one substitute for a check
of the other.

**Visual:** check the world's own Source Registry for Native rows (not Excluded) that
could license a photograph or artifact image. *Precedent:* PAHC — the single
strongest tour candidate in the portfolio — has **zero** visual license
(archaeologically invisible, plus Excluded rows); description-first is a *necessity*
there, not a budget choice (§3.1). Desert's Kellia excavation findings, by contrast,
**are** Native, registered sources (Doc_02 §5.1) — the one world in the portfolio
where a visual layer already has an evidentiary license (§2.4).

**Audio:** check whether any oral/sung/spoken performative moment is *actually
attested in the source text itself* — a teaching being given, a hymn sung, a text read
aloud — as distinct from a scene that could merely be *imagined* with sound. Audio is
licensed only for the former. If the scene calls for a sound with no attested performer
or text (background ambience, "what the room might generally have sounded like"),
that is out of scope regardless of plausibility, and a disclaimer does not rescue it —
"text can hedge mid-sentence; sound cannot" (§2.6). A period-adjacent substitute
(another culture's notated music, a living tradition's present-day performance) is
barred by the cross-contamination discipline unless separately, explicitly approved as
a labeled outside-this-world exhibit that is never blended into the scene itself — and
that approval is Mark's boundary call, not a default (§3.2 Sound findings, options c/d).

## Gate 7 — Verdict

Record the finding in the same shape as the Strategy document's own §3.0 lookup table,
so a future builder can look up "is a tour possible for World X, and on what basis"
without re-deriving this analysis:

| Field | Answer |
|---|---|
| World | |
| **Tour verdict** | YES (strongest case) / QUALIFIED YES (Class B only) / PARTIAL (name what it does and doesn't support) / PARTIAL-THIN / NOT ASSESSABLE — NO TOUR |
| Anchor scene (ID, evidentiary Tier) | |
| Tour class | A / B / none |
| Gate 2 finding (narrated vs. thin mention) | |
| Decline-stop content (Gate 5) | |
| Visual/audio eligibility (Gate 6) | |
| Hardest constraint (Gate 4) | |
| Open boundary calls for Mark | |

**A verdict of NO TOUR, PARTIAL, or PARTIAL-THIN is a complete and correct answer, not
an incomplete one.** The module's own founding rule is that absence is an honest
finding, never a gap to fill: "'We could imagine a plausible service based on general
Christian custom of the era' is precisely the move this module exists to refuse — for a
sentence, for a beat, and for an image alike" (Strategy §5).

## What this document does not resolve (flagged, not invented around)

This Gate has only ever been *reverse-engineered* from a single pass across five
worlds done by one thread in one day — it has not itself been run fresh, end-to-end,
against a new world by a different builder. Whether the eight gates as sequenced here
actually hold up under that kind of independent second use, or whether a real future
run surfaces a step this document's extraction missed, is an open question this
document cannot answer from the inside. Flagged here rather than claimed as
already-validated.
