## Discovery methodology note

No `records/don/search_record/` was kept as searches happened during this build, unlike the per-search logging some other worlds in this project maintain. The Discovery column above was reconstructed together with this Registry's own drafting and revision passes, dated to when each entry was written rather than to a contemporaneous log of the search that found it. This is disclosed rather than presented as the kind of running record Construction Framework V7.4 Step 2 describes; a future pass that wants that discipline for this world would need to open `records/don/search_record/` going forward, not back-fill one for what has already happened.
