## 1. OPEN requests — public domain, real acquisition candidates

Numbered G1–G7, this project's own convention for the individual requests inside a world's own Source Request Manifest (see `world-build-docs/desert/SOURCE-REQUEST-MANIFEST.md` and `world-build-docs/alx/SOURCE-REQUEST-MANIFEST.md` for the same numbering in other worlds' builds).

Five of these seven (G1–G5) were found by live web search this session and carry a specific "where" URL, not fetched or opened from inside this session (this session's outbound network access blocks archive.org, Gallica, and general web domains directly — see the note at the end of this section). The remaining two (G6, G7) are named from this build's own field knowledge, with no specific URL located this session — a further search is needed before either can move to a Destination. The project lead or a later session with broader network access should open each link and confirm it delivers full text before treating it as settled.

**G1. Tyconius, *Liber Regularum* — F.C. Burkitt (ed.), *The Book of Rules of Tyconius, Newly Edited from the MSS.* (Texts and Studies III/I, Cambridge University Press, 1894).** Public domain (1894). Latin critical text with an English scholarly introduction; no English translation of the Rules themselves. Three Internet Archive items were found hosting this edition: `archive.org/details/bookofrulesoftyc00ticouoft`, `archive.org/details/rulesoftyconius00tico`, and `archive.org/details/in.ernet.dli.2015.167130` (a 244-page Digital Library of India scan of the same printing). Registry rows 15, 41. **Vendored file:** `cic/texts/tyconius_liber-regularum_burkitt1894.txt` — Mark downloaded the first of the three items (`bookofrulesoftyc00ticouoft`, FULL TEXT/OCR format) and supplied it 2026-09-01 as a DOCX attachment; the file is confirmed as the genuine Burkitt 1894 edition (preface, table of contents, and introduction all present) and public domain on two independent grounds stated in its own header (archive.org's copyright-evidence record for this item, and the 1894 publication date alone). The delivered format is plain OCR text rather than PDF, so the Destination corrected to `.txt` from this entry's own original `.pdf` placeholder, as anticipated below.

**G2. Optatus, critical Latin text — Karl Ziwsa (ed.), *S. Optati Milevitani libri VII*, CSEL 26 (Vienna: Tempsky, 1893).** Public domain. This is the critical edition underlying the already-vendored 1917 Vassall-Phillips translation (row 1); acquiring it would let this build settle the second-edition/Book-count questions row 1's Verification Note currently leaves open from the translation alone. Not independently located at a specific URL this session — a further search is needed before this can move to a Destination. Registry row 38.

**G3. Codex Theodosianus, Book 16 — Theodor Mommsen and Paul M. Meyer (eds.), *Theodosiani Libri XVI cum Constitutionibus Sirmondianis* (Berlin: Weidmann, 1905).** Public domain (1905). The standard critical Latin edition, in two volumes (the first in two parts). A direct plain-text stream of a scanned copy was found at `archive.org/stream/theodosianilibri02code/theodosianilibri02code_djvu.txt` (main item page `archive.org/details/theodosianilibri02code`), which — being a text stream rather than a lending interface — should not require a borrow step; a second, separately-scanned copy was also found at `archive.org/details/theodosianilibri0002unse`. Registry row 16. **Destination if acquired:** `codex-theodosianus_book16_mommsen1905.txt`, trimmed to Book 16 from whichever volume carries it. Clyde Pharr's 1952 English translation is the only full English translation reported to exist, but it is not public domain (see §2 below) — this project has already reached the same determination for the identical work in a different world's build (`world-build-docs/ijc/SOURCE-REQUEST-MANIFEST.md` §3: "Theodosian Code in English — Pharr (1952) treated as in copyright, fails closed"), so this is a confirmed, not merely inferred, closure.

**G4. Passio Marculi and Passio Isaac et Maximiani — as printed in J.-P. Migne (ed.), *Patrologia Latina*, vol. 8 (Paris, compiled 1844).** Public domain. The *Passio Marculi* is independently confirmed this session, by two separate search results, at columns 760–766 (headed *Passio Benedicti Martyris Marculi*); neither text has a modern critical edition. An Internet Archive item hosting a Google Books scan, `archive.org/details/patrologiae_cursus_completus_lat_vol_008`, was described in this session's own search results as offering free download rather than only streaming or borrowing — Google-Books-sourced Internet Archive scans of out-of-copyright volumes are typically freely downloadable, unlike controlled-lending library scans, though this was not opened and confirmed directly. An earlier lead pointing to a Gallica digitization of the same Migne volume could not be re-confirmed this session (no ark identifier re-found) and should be treated as an unconfirmed, separate lead rather than a second source. Registry rows 19, 20. **Destination if acquired:** `passio-marculi-isaac-maximiani_migne-pl8.pdf`. Latin only — the modern standard English translation is Tilley's *Donatist Martyr Stories* (§2 below), in copyright; Monceaux (G6 below) is a second, independent public-domain route if this text proves unsatisfactory.

**G5. Augustine's anti-Donatist works, critical Latin text — Michael Petschenig (ed.), *Sancti Aureli Augustini Scripta contra Donatistas*, CSEL 51–53 (Vienna: Tempsky, 1908–1910).** Public domain. This is the critical Latin edition of *Contra Cresconium* and *Contra epistulam Parmeniani* (Registry rows 17, 18). Doc_01 §7 item 6's binding to track these two works for acquisition is discharged by their being named here and in the Registry (Doc_02 §10); acquiring this edition would additionally put their full texts, currently unvendored in any form, into the library. Not independently located at a specific URL this session — a further search is needed before this can move to a Destination. Registry row 39.

**G6. Paul Monceaux, *Histoire littéraire de l'Afrique chrétienne depuis les origines jusqu'à l'invasion arabe*, vols. IV–VI (Paris: Ernest Leroux, 1912–1922).** Public domain (pre-1929). The standard older literary history of Donatism, reported to print the Donatist documentary and martyr-narrative corpus with commentary — a second, independent public-domain route to the Passiones (G4 above) if Migne's uncritical text proves unsatisfactory, and the most efficient single answer to this Registry's own edition-level gap. Not independently located at a specific URL this session. Registry row 40.

**G7. *Corpus Inscriptionum Latinarum*, vol. VIII, *Inscriptiones Africae Latinae* (Berlin: Reimer, 1881–, with supplements).** The early volumes (1881 and following) are public domain, unlike the field's other reference instruments named in §3 below. The standard epigraphic corpus for Roman North Africa, and the instrument that would move Registry row 27's *Deo laudes* claim off a recognized-category generality onto a specific catalogued inscription — a standing priority-review flag since this world's first Registry draft. Not independently located at a specific volume or fascicle URL this session. Registry row 48.

**A network-access limitation, disclosed rather than papered over:** this build session's outbound network access blocks direct fetch of the specific pages named above — archive.org, Gallica, and general web domains all returned an egress-blocked error when checked directly from inside this session, consistent with this project's own standing note in `cic/texts/README.md` that its build sandbox blocks every patristic text host. Every "where" reference above is a real result returned by a live web search this session — a genuine title, publisher, series, and URL, not invented — but none has been opened and inspected page-by-page from inside this session. Before treating any item above as ready to vendor: (a) open the link and confirm it actually delivers full text under free access, not a preview or a lending checkout; (b) once downloaded, follow the corpus's own vendoring steps — write a provenance header into the file stating its public-domain basis, per `cic/texts/README.md`, and run `python cic/engine/texts_registry.py --write-readme` after adding the `ENTRIES` row for it, so the census and this Registry's own corpus-map dependency stay in sync.

## 2. Confirmed unavailable in public domain (recorded, not requested)

These are named for completeness and to close off the temptation to reach for them, not as things to acquire. Nothing below gets a Destination filename.

- **Gesta Collationis Carthaginiensis, critical edition and translation** — Serge Lancel (ed.), *Actes de la Conférence de Carthage en 411* (Sources Chrétiennes 194, 195, 224, 373, Paris: Cerf, 1972–1991) and *Gesta conlationis Carthaginiensis anno 411* (CCSL 149A, Turnhout: Brepols, 1974). Both series are modern, actively-copyrighted critical editions. An archive.org item (`archive.org/details/actesdelaconfere0003coun`) exists for the Lancel/SC edition but is presumed controlled-digital-lending rather than free download, consistent with how in-copyright critical editions are typically hosted there. No public-domain edition of this text, in any language, was identified this session. Registry row 14.
- **Tyconius, *Liber Regularum*, modern English translation** — William S. Babcock (trans.), *Tyconius: The Book of Rules* (SBL, Texts and Translations 31, 1989). In copyright.
- **Codex Theodosianus, English translation** — Clyde Pharr (trans.), *The Theodosian Code and Novels and the Sirmondian Constitutions* (Princeton University Press, 1952; reprinted by The Lawbook Exchange, 2001, 2012). In copyright — still in active commercial print via the reprint, and this project has already reached the same conclusion for the same work in a different world's manifest (see G3 above). `earlychurchtexts.com`, a possible source of free English excerpts, is blocked by this session's own network policy and could not be checked; this remains a genuinely open research question for a session with broader access, not a closed one, but it does not change this work's own copyright status.
- **Optatus, modern English translation** — M. Edwards (trans.), *Optatus: Against the Donatists*, Translated Texts for Historians 27 (Liverpool University Press, 1997). In copyright; an alternative to the vendored 1917 Vassall-Phillips translation. Registry row 45.
- **Optatus, current critical edition and French translation** — M. Labrousse (ed. and trans.), *Optat de Milève: Traité contre les donatistes*, Sources Chrétiennes 412–413 (Paris: Cerf, 1995–1996). In copyright. Registry row 44.
- **Donatist martyr narratives, modern English translation** — Maureen A. Tilley (trans.), *Donatist Martyr Stories: The Church in Conflict in Roman North Africa* (Translated Texts for Historians 24, Liverpool University Press, 1996). In copyright. Registry row 35.
- **Collected Donatist documentary dossier** — Jean-Louis Maier, *Le Dossier du Donatisme*, 2 vols. (Texte und Untersuchungen 134/135, Berlin: Akademie-Verlag, 1987/1989). In copyright (Akademie-Verlag, now De Gruyter). Registry row 36.

Any of these seven can still be bought or consulted through a library without being vendored — that is a legitimate research path, distinct from placing a file in `cic/texts/`. Babcock and Pharr are named here without their own Registry rows, since neither is cited for a specific claim this build draws on; Registry rows 14 (*Gesta*), 35 (Tilley), 36 (Maier), 44 (Labrousse), and 45 (Edwards) are what "not currently vendored" means for the works that do have rows — a status distinct from "unusable."
