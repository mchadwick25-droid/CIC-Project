## 0. What This Document Does

Step 3 (`Doc_03_Lexicon_Candidate_List.md`) produced a 21-term candidate list with preliminary tiers, tags, and Author-Gravity flags, deliberately undeveloped so that gravity discovery could test candidates in this world's own vocabulary rather than in imported analytical language. Now that gravity discovery (Doc_04) and ecological reconstruction (Doc_05) are complete, this document:

1. **Assigns permanent `donlex` numbers** to the full 21-term roster, ordered by Doc_03's own six thematic clusters rather than alphabetically, so the numbering itself preserves the ecology's own conceptual groupings (§1 below sets out the full assignment).
2. **Confirms tiers against Doc_04 and Doc_05.** A term earns Tier-1 (full three-level treatment plus a deployment chunk built this cycle) only where the confirmed gravity spine gives it organizing weight. §1 records one tier change from Doc_03's own preliminary estimate.
3. **Specifies the CT Contest Type** for the one [CT] term this world's roster carries (Article 26; §2 below).
4. **Produces deployment chunk files** for the confirmed Tier-1 terms this cycle, built to the Deployment Lexicon Chunk Template, each with Quick Meaning / World Meaning (from-inside) / Ecological Function / Distortion Risk / Key Sources / CT Contest Type (where applicable) / Reported-Experience Status (where applicable). §3 records what was built and what remains disclosed deployment-layer follow-on.
5. **Builds the master Deployment Lexicon index** (§4) covering the full roster, and runs an honest Related-Terms reciprocity check limited to what is actually built this cycle.

**Scope and disclosed deferral.** This is a 21-term lexicon — small enough, relative to the multi-hundred-term lexicons other confirmed worlds in this project's portfolio have produced, that the Tiered Depth Principle's own warning against inflating Tier-1 bears real weight here: only seven of the twenty-one terms earn Tier-1 treatment. This cycle builds full deployment chunks for **all seven confirmed Tier-1 terms** — the whole Tier-1 set, not a partial subset, since a seven-term Tier-1 roster is small enough to complete in one pass rather than requiring the phased "gravity-central first, gap-closure later" approach a larger lexicon would need. The **fourteen Tier-2 and Tier-3 terms** are fully specified in the master index (tier, tags, AG-risk, CT status) but their own deployment chunk files are **not** built this cycle — named here as deliberate, disclosed deferral, not a silent omission, consistent with this project's own established practice for lexicon cycles of this kind.

## 3. Deployment Chunk Production (this cycle)

Built to the Deployment Lexicon Chunk Template V1.0, in `Lexicon-Chunks/` — **all seven confirmed Tier-1 chunk files (`donlex001`–`donlex019`, non-sequential per the cluster-ordered numbering in §1) are produced this cycle.**

- `001_traditor-traditio` · `002_rebaptism` · `008_church-ecclesia` · `010_martyr-martyrdom` · `015_bishop-episcopus` · `018_agonistici` (exercises the CT Contest Type section) · `019_refusal-of-imperial-legitimacy`.

Each carries: retrieval front-matter (Term, World-Code, Tier, Tags, Aliases, Related-Terms, Retrieve-When, Do-Not-Retrieve-When); a required `## Quick Meaning`; a from-inside `## World Meaning` (several paragraphs, per the Tier-1 depth requirement); `## Ecological Function`; `## Distortion Risk` (Modern Hearing / World Hearing pairing); `## Key Sources` (with Author-Gravity notes, since every one of this world's Tier-1 terms carries some degree of Author Gravity concentration); `## CT Contest Type` (Agonistici only); and a `## Related-Terms Reciprocity Note`. Final-Assembly checks applied to each: no analytical-distance markers in World Meaning; Quick Meaning present and non-empty; the one CT entry's Contest Type completed, not left templated.

**No term this cycle carries Reported-Experience Status.** That status is reserved for a term whose World Meaning is historically uncertain but formationally central — every one of this world's seven Tier-1 terms is, instead, historically Documented at its core (per Doc_04's own Confidence/Gravity Cross-Check findings for G1, G2, G3, G4, G5), with any divergence between core-doctrine confidence and specific-argumentative-texture confidence disclosed as an Author-Gravity note in Key Sources rather than requiring the Reported-Experience marker. This is stated explicitly here, following this project's own established practice of confirming the status was considered and found inapplicable, rather than leaving its absence unexplained.

**Tier-2 and Tier-3 chunk files: disclosed deferral.** The fourteen Tier-2 and Tier-3 terms (`donlex003`–`007`, `009`, `011`–`014`, `016`–`017`, `020`–`021`) remain **specified but not yet produced as deployment chunk files.** Their tier, tags, CT status (none — the roster's sole CT term is Tier-1), and Author-Gravity flags are fully carried in the master index (§4). This is deployment-layer follow-on work, named here rather than silently omitted, consistent with the Interpretive Lexicon Development Framework's own tiered-depth discipline: a 21-term lexicon whose seven organizing terms are complete supports meaningful runtime retrieval and Level 2/3 transparency for this world's own gravity-central vocabulary immediately, without requiring the full 21-chunk set to be built before this document can be disposed.
