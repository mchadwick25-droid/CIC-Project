## I. AS/SC tag assignment for ministrae, hetaeria, pertinacia

Checked directly against LDF Part II's actual text:
- **[AS] — Signature Vocabulary:** "Vocabulary unique or substantially distinctive to this formation world, unlikely to carry equivalent weight in neighboring worlds."
- **[SC] — Shared Vocabulary:** "Vocabulary common across Christian tradition broadly, which this world uses with its own distinctive assumptions, emphasis, or implications."

Doc_06's Section 3 disclosure states: "AS as defined in LDF Part II ('**unique or near-unique to this world**') is written with the world's own vocabulary in mind... This is a deliberate extension of AS's functional intent (distinctiveness to this world) rather than its most literal reading (**native to this world**)."

**This is a fabricated quotation, SUBSTANTIAL.** The phrase "unique or near-unique to this world," presented in quotation marks as if from LDF Part II, does not appear anywhere in the actual Framework text. The real definition ("unique or substantially distinctive to this formation world, **unlikely to carry equivalent weight in neighboring worlds**") says nothing about nativity or origin within the world's own vocabulary — it is about whether the term would carry equivalent weight in a *different* formation world, a test these three Latin outside-terms plainly pass (they are unique to this world's own encounter with Roman legal process and would carry no weight in, e.g., a different formation world's own lexicon). On the real definition, AS applies to ministrae/hetaeria/pertinacia cleanly, without needing any "deliberate extension" — Doc_06 has invented an unnecessary tension by misquoting the rule it claims to be stretching. The tagging *decision* (AS) is very likely still correct; the *reasoning offered for it*, including a quoted phrase attributed to the governing Framework, does not hold up against the actual document.

## J. General structural completeness against LDF Parts I–IX

- **Part VII (Cross-World Consistency) — misapplied citation, SUBSTANTIAL.** Doc_06 Section 1, Open Item 4 invokes "the LDF's own Part VII (Cross-World Consistency)" to support treating ministrae/hetaeria/pertinacia's relevance to *both* the Lexicon and Doc_08's Forces Document as normal. But Part VII's actual subject is entirely different: it governs how the *same term* should be treated when it recurs *across different formation worlds* (e.g., a term shared between World #1 and a hypothetical World #3), explicitly to prevent assuming cross-world equivalence. It says nothing about a single term's relevance to multiple downstream documents *within* one world. Doc_06 cites the wrong Framework section for the claim it is making; the underlying practical point (a term can matter to both the lexicon and the Forces Document) may still be reasonable, but it is not what Part VII says, and a reviewer checking the citation would find it does not support the sentence it is attached to.
- **Part III's "Key Texts" vs "Key Sources" — framework-level ambiguity, not clearly a Doc_06 defect.** LDF Part III (line 128–129) lists "Key Texts" and "Key Sources" as two *separate* required Tier 1 elements. Neither the authoritative Deployment Lexicon Chunk Template nor Part VI's own chunk-structure list (which enumerates only "Key Sources") includes a distinct "Key Texts" section. Doc_06 and all 13 chunks follow the Template's actual structure (Key Sources only), which is defensible given the Template is the more specific, later-authored governing document — but Doc_06's governance line claims "LDF V2.1, Parts I–IX in full," and Part III's literal text is not fully satisfied by that structure. **COSMETIC** (a pre-existing framework inconsistency Doc_06 inherited rather than created, and the Template's authority is a reasonable resolution) but worth naming rather than leaving invisible.

## Additional finding: the "agape" label's core evidentiary premise is independently found to be inaccurate

This does not map cleanly onto a single lettered item but is the most significant finding of this review, so it is stated on its own.

Doc_02, Doc_03, and Doc_06 (via pahclex010) all build the "agape" label entry on the claim that no one inside the community ever names this meal — the World Meaning states: "the one voice describing it never says, and **no voice from inside the community answers the question either**." The entry's whole CT Contest Type argument depends on "agape" being purely a modern label imposed on Pliny's outside description, "not primary-source-anchored" (Doc_03 2.10).

This is factually incorrect. **Ignatius's Letter to the Smyrnaeans, chapter 8** — a passage Doc_04, Doc_03, and Doc_06 all already cite extensively elsewhere in this same lexicon (for the bishop-validated-eucharist point in eucharistia's and diakonos's own Key Sources) — contains the sentence: "It is not lawful without the bishop either to baptize or to **celebrate a love-feast**" (ἀγάπην ποιεῖν in the Greek; verified directly against the Roberts-Donaldson/ANF text, newadvent.org/fathers/0109.htm, the same translation tradition Doc_03's own round-4 review used to verify its Ignatius citations). This is Ignatius — a Native, inside voice already load-bearing throughout this entire document — using the actual term "love-feast" (agape) for a communal meal practice requiring the bishop's authorization, in the identical letter (Smyrnaeans 8) this project's own build already cites for a different clause in the same chapter.

This means "agape" is not merely a modern label retrofitted onto Pliny's outside description; it has direct Native/primary-source grounding as an in-world term for a community meal practice, independent of and prior to any modern scholarly labeling exercise. The claim "no voice from inside the community answers the question either" is demonstrably false on this world's own developed evidentiary base (Smyrnaeans 8 is already a Registry-anchored source in this build).

This error originates upstream in Doc_02/Doc_03 (Doc_06 inherited rather than invented it), but Doc_06 had every opportunity to catch it — Smyrnaeans 8 is already one of its own Key Sources elsewhere in the same document — and the LDF's own Confidence Inheritance Principle and Part VIII's "genuine, identifiable sources, accurately represented" standard place responsibility on this step to verify inherited claims, not merely repeat them. **SUBSTANTIAL** — this changes a sourcing conclusion and potentially the entry's entire framing (from "modern label with no inside-voice anchor" to "a genuine, if under-examined, Native term whose relationship to Pliny's meal and to the eucharist remains contested").
