Their later, non-eyewitness character is instead captured in the Confidence tier and Verification Note, which is the schema-compliant place for that distinction.
- Rows 27–35 (Confidence B) correctly reflect that this build did not independently re-consult any of these secondary works this session; they are used as named, credible references at the confidence level the Template actually defines for that condition, not overstated as freshly verified.
- This Registry will grow as later steps (Doc_03 onward) surface new candidate sources, per the living-document, append-only discipline — new rows continue the numbering; nothing already entered is renumbered or removed, even if a later step finds a source unreliable (it would instead move to Confidence E, marked removed-from-use, per the Template).
