- **No story exists from a Homoian Christian's own narrative perspective**, despite the binding Homoian-recentering disclosure obligation (Step 0 §4.1, Doc_02 §7) — this world's own Registry has exactly one piece of near-primary Homoian self-testimony (Auxentius's fragmentary letter, row 23), and it is a theological letter fragment, not a narrative with story structure; it cannot honestly be rendered as a "story" without inventing narrative content the fragment itself does not supply. This is itself a formationally significant absence: the losing side of this world's own central conflict left this world's own record with a theological argument but no story.
- **No story exists for Strand C beyond the single 386 crisis** (`ijcstory004`) — Doc_01 §4's own finding that Strand C does not persist as an independent claim-making stream to this world's 451 close means this world's own narrative record for that strand is genuinely bounded to one dramatic episode, not thin coverage of a richer life; there is no second Strand C story this document declined to tell, because none exists in the Native record.
- **No story exists for Damasus's own martyr-cult program beyond its general character.** Doc_02 §4 flagged this program as itself a formation-narrative source, but this world's own record, as this build has assembled it, does not preserve a specific, individually-attested martyr narrative from within that program with enough textual detail to tell as its own story (as opposed to describing the program's own existence and function, already done at Doc_02 §1, §4 and Doc_05 §7). Naming this precisely: the epigraphic corpus is well-attested as a *program*; it is not, in this build's own current source base, attested at the level of an individual martyr's own told story. This is flagged as a possible future addition if a specific Damasan epigram's own narrative content is identified and added to the Registry under its own living-document discipline — not silently worked around here.
- **No Tier 2 (Collected and Traditional Material) story exists in this inventory at all.** Named as a real pattern, not an oversight (§1 above): this world's own institutional-juridical character does not generate the kind of community-transmitted, author-unattributed tradition Tier 2 is built for — every narrative this world's own record preserves comes with a named author attached, consistent with Doc_02's own finding that this world's source base is disproportionately elite and individually-authored.
