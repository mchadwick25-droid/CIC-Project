**Schema.** Exactly the Template's fields — #, Source, Type (P/S/M/L), Confidence (A–E), Boundary Status (Native/Excluded only), Exclusion Reason (Out-of-Boundary / Named Comparandum; blank if Native), Licensed For (blank if Excluded), Verification Note, Comparandum Note (required if Named Comparandum), Added — plus one column the fleet's Gallic Registry already carries and Template step 4 presupposes: **Discovery** (channel / instrument / date), so that rows found from the builder's prior knowledge and not read this session are visibly flagged for independent second-opinion review. **Boundary Status is restricted to exactly Native or Excluded**; a grep of the live table for any other value in that column was run before this header was written and found none.

**Conventions.** Confidence uses the Source Registry Template's Citation Reliability tiers verbatim: **A** — "Verified this session against an accessible primary source, translation, or authoritative reference"; **B** — "Specific work/locus named, not independently re-checked this session"; **C** — "Tied to a real author/work, no specific locus pinpointed"; **D** — "Tradition/genre-level attribution, no specific text/author named"; **E** — "No traceable source. Not a resting tier — remove or re-ground to at least D." (**the second sentence restored at Revision 2, Round 2 N5** — Revision 1's Conventions paragraph dropped it while claiming a verbatim quotation; no row is at E, so the tallies are unaffected, but the paragraph's own claim to be verbatim now is.) Two applications are stated so the letter is a usable filter: (i) A is granted only where the cited locus was itself opened and read this session (the vendored file at the line; a fetched document), or where the bibliographic citation was checked against a named catalogue or library record (e.g., R27's HathiTrust and Valparaiso records, R86's SLUB/DDB record); a work whose existence this session confirmed only through web-search summaries or reviews, or whose line locus was taken from the corpus-map and not opened, stays at B, because the locus — the thing a downstream step will cite — was not re-checked. (ii) Tertiary sources (R83, R89, R90) are capped at B whatever was read, since a tertiary article is not an "authoritative reference." **Whether a text was read is not what the letter records**: every row states that in its Verification Note, and rows that mix read and unread material split the tier ("A (intro) / B (text)"). For the two OCR-degraded files (v3, Cole *Bondage*), "A" is granted only for the specific passage read and re-checked; no general clearance is implied. **"(context)" rows** — opponent texts this world's own writings directly answered — carry Boundary Status **Native** with the marker **(context)** at the head of their Licensed For field, following the Gallic Registry's precedent (its Augustine rows): Native because actually drawn on in this world's formation, licensed only for the opponent's position *as this world's own texts represent it*, never for the opponent's own voice.
