## SUBSTANTIAL FINDINGS

### F1 [SUBSTANTIAL] — The Antony "non-literate data point" is self-contradictory and contradicts the cleared upstream docs
**Location:** §1 generation table (C1 row: "core corroborated by Clement/Athanasius + Antony (non-literate)"); §3.1 Cross-Check ("the single non-literate data point, Antony" carrying the core to Widely Accepted; then "the sole beyond-literate evidence, Antony, is Tier-3 hagiography of insufficient weight"); §5 bullet 1; xlsx `Candidates` C1 AG-risk cell and `Cross-Build` sheet row 4.

**What's wrong — two linked defects:**

1. **Internal contradiction on whether Antony is load-bearing.** §1 and §3.1 enlist Antony as *corroboration* that lifts C1's core to "Widely Accepted" (it is named alongside Clement and Athanasius as the non-Origen evidence carrying the core). Yet §5, §3.1's own Cross-Check clause, and the xlsx `Cross-Build` sheet ("Used only as insufficient-weight evidence; NOT load-bearing for any Alexandrian ecology-wide gravity") say the opposite. A data point cannot both help carry the core to WA and be non-load-bearing insufficient weight. If the core reaches WA on the literate witnesses alone (Clement earlier, Athanasius later), Antony adds nothing and should be dropped from the corroboration list; if it is doing corroborative work, the "insufficient weight" disclaimer is false.

2. **"Non-literate" contradicts the world's own carried finding and the scholarship.** Doc_01 §3.3 and Doc_02 §4/§5 carry Antony's literacy as **Contested**, foregrounding Rubenson's argument (from the *Letters of St. Antony*) that Antony was in fact *literate* and an Origenist thinker and that Athanasius's illiterate-holy-man portrait is a deliberate construction. Web check confirms this is precisely Rubenson's thesis and that it is the live, contested reading (see Sources). Doc_04 flatly labels Antony "non-literate" — taking a side on a Contested question, and the side *against* the very scholar the upstream docs put front and centre. Worse, "non-literate" is the load-bearing premise for using Antony as the "sole beyond-literate" reach in the stratum-bias argument; if Antony was literate (Rubenson) he is not beyond-literate evidence at all, which weakens (not strengthens) the draft's own point.

**Evidence:** Doc_01 §3.3 ("Contested for Antony's literacy … explicitly held open"); Doc_02 §4 (Rubenson entry) and §5 item 2 cross-build note ("Rubenson's literate-Antony argument means even the 'unlettered' premise is contested"); Rubenson, *The Letters of St. Antony* (Lund 1990) — https://digitalcommons.lmu.edu/cgi/viewcontent.cgi?article=1050&context=theo_fac and https://www.cambridge.org/core/journals/church-history/article/abs/letters-of-st-antony-origenist-theology-monastic-tradition-and-the-making-of-a-saint-...

**Concrete fix:** (a) Remove Antony from the C1-core *corroboration* set in §1 and §3.1; the core reaches WA on Clement + Athanasius within the literate stratum without it. (b) Where Antony is discussed as beyond-literate reach in §5, replace "non-literate data point" with the carried Contested framing — e.g., "the Antony material (desert-attributed, Tier-3, and itself contested as to literacy per Rubenson; Doc_01 §3.3)" — and state plainly that it is *not* relied on, consistent with the `Cross-Build` sheet. (c) Propagate the wording to the xlsx C1 AG-risk cell.

### F2 [SUBSTANTIAL] — Candidate-ID collision: C4 and C5 denote different candidates in §1 vs. §3/§4/xlsx
**Location:** §1 generation table (C4 = "Participation↔Perception Dynamic"; C5 = "Logos-Centered Unity"; C6 = "Theosis as Horizon"; C7 = "Learning-Formation Integration") vs. §3.4 / §3.5 / §4 index table / xlsx `Candidates` sheet (C4 = "Logos-Centered Unity"; C5 = "Learning-Formation Integration").

**What's wrong:** The same IDs mean different candidates within one document. In §1, **C5 = Logos-Centered Unity**; in §3.4, §4, and the xlsx, **C4 = Logos-Centered Unity** and **C5 = Learning-Formation Integration**. §1's C4 (Participation↔Perception) and C6 (Theosis) are silently dropped/remapped to Formation Dynamics. §3.4 flags the renumber in a single parenthetical ("Renumbered from source's C5…"), but §1 itself is never reconciled: a reviewer or downstream builder who cross-references "C5" lands on Logos in §1 and on Learning-Formation everywhere else. This directly defeats the one job Template V1.0's required index table exists to do — let someone confirm a candidate's testing "without reading the full document." The xlsx ID column (C4 = Logos) therefore does **not** match the narrative's §1 ID field — the sole ID-level narrative↔index mismatch.

**Evidence:** compare Doc_04 line 42–45 (§1 table) with lines 97–106 (§3.4/§3.5), lines 135–139 (§4 index table), and xlsx `Candidates` rows C4/C5.

**Concrete fix:** Renumber §1's generation table to the final scheme used everywhere else (C4 = Logos-Centered Unity; C5 = Learning-Formation Integration), and list the three Formation Dynamics under their D-A/D-B/D-C or descriptive labels rather than reusing C4/C6. Alternatively, keep §1 as the "raw digest" numbering but add an explicit crosswalk line mapping digest-C4/C5/C6/C7 → final IDs. Either removes the collision.

### F4 [COSMETIC] — The "single phase scheme" leaves an unassigned 254–296 gap
**Location:** §0 "Single phase scheme"; build note (claims it corrected the source's "unreconciled dual phase-dating scheme").
**What's wrong:** Mid = Origen (c. 215–254); Late = Athanasius/Didymus (c. 296–400). Nothing covers c. 254–296 (~42 years: Dionysius's episcopate, Heraclas, the Decian and early Diocletianic-era horizon). The section frames the phase relationship as "overlap … because the figures' floruits overlap," but 254→296 is a *gap*, not an overlap. The claim to have replaced a messy dual scheme with a clean single one is slightly overstated while a coverage hole remains.
**Fix:** Either extend Mid's endpoint / Late's start to close the gap, or add a one-line "inter-phase" note naming who dominates attestation c. 254–296 (Dionysius; the post-Origen teachers) so the scheme is gapless.

### F5 [COSMETIC] — xlsx T3 source-stream attribution includes Stream 8 (Martyr Memory)
