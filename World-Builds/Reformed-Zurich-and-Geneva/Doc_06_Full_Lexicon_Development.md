## 0. What This Document Does

Step 3 (`Doc_03_Lexicon_Candidate_List.md`) produced a 19-term candidate list (corrected from an original miscount of 18 — see Doc_03's own inline correction note) with preliminary tiers, tags, and Author-Gravity flags, deliberately undeveloped so that gravity discovery could test candidates in this world's own vocabulary rather than imported analytical language. Now that gravity discovery (Doc_04) and ecological reconstruction (Doc_05) are complete, this document:

1. **Assigns permanent `rzglex` numbers** to the full 19-term roster, ordered by Doc_03's own six thematic clusters rather than alphabetically, so the numbering itself preserves the ecology's own conceptual groupings (§1 below).
2. **Confirms tiers against Doc_04 and Doc_05**, including one promotion (Sola Scriptura, Tier 2 → Tier 1) and two disclosed merges of closely-related Tier-1 candidates into single deployment chunks, reasoned explicitly rather than left implicit.
3. **Specifies the CT Contest Type** for the one [CT] term this world's roster carries (Article 26; §2 below).
4. **Produces deployment chunk files** for the confirmed Tier-1 terms this cycle, built to the Deployment Lexicon Chunk Template, each with Quick Meaning / World Meaning (from-inside, per strand where the strand division matters) / Ecological Function / Distortion Risk / Key Sources / CT Contest Type (where applicable) (§3).
5. **Builds the master Deployment Lexicon index** (§4) covering the full roster, and runs an honest Related-Terms reciprocity check limited to what is actually built this cycle.

**Scope and disclosed deferral.** This is a 19-term lexicon, small relative to lexicons running well over a hundred terms elsewhere in this project's portfolio. Six deployment chunks are built this cycle, covering all six confirmed Tier-1 slots (after the merges and promotion below reduce the original 7 preliminary-Tier-1 rows to 6 deployment-ready chunks representing 8 candidate terms). The **eleven remaining Tier-2 and Tier-3 terms** are fully specified in the master index (tier, tags, AG-risk, CT status — none) but their own deployment chunk files are **not** built this cycle — named here as deliberate, disclosed deferral, consistent with this project's own established practice (Donatism's own Doc_06 deferred 14 of 21 terms on the same reasoning).
