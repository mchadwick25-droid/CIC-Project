**Raised by:** the `lpc` build thread. **Authorised for routing by the project lead, 2026-09-16.**
**Why this exists:** three defects sit inside L3 governing files and L4 templates. **A build thread's write access is scoped to its own world's build folder**, so none of them can be fixed from here — and each one re-appears in every world that reaches the step it governs. `lpc` has now carried all three as open portfolio items through Doc_05, Doc_06, Doc_07, Doc_08 and the World Profile without being able to close any of them.

**Nothing here is an `lpc` problem.** Each is stated with its sites so a coach thread can act without re-deriving it.

**What is already settled:** the project lead ruled on 2026-09-14 that **Boundary Structures** is canonical, and `lpc` uses it throughout. **What the ruling cannot do is fix the files.** Until the six sites are reconciled, every world reaching Step 5 meets the same contradiction and has to re-derive the same answer.

## 2. Key Texts / Key Sources — a template that cannot satisfy its own Framework

**Interpretive Lexicon Development Framework V2.1, Part III** names **Key Texts** and **Key Sources** as two distinct required sections of a Tier 1 lexicon entry. **`L4-Templates/Deployment_Lexicon_Chunk_Template.md` has only Key Sources.**

**Verified across the portfolio: zero chunks in any world carry a Key Texts section.** Seven worlds have `Lexicon-Chunks/` — Alexandria, Desert, Donatism, Hieronymian, Imperial-Juridical, `lpc`, Syriac. Every Tier 1 entry in all seven is non-conformant to the Framework, or the Framework is wrong. It cannot be both.

**Files:** `L3B-World-Build-Methodology/CiC_L3B_Interpretive_Lexicon_Development_Framework_V2.1.docx`; `L4-Templates/Deployment_Lexicon_Chunk_Template.md`.

**The decision is which document is authoritative**, and it is not a build thread's to make:
- If the Framework is right, the L4 template needs a Key Texts section and **every Tier 1 chunk in seven worlds is incomplete**.
- If the template is right, the Framework's Part III section list needs correcting.
- If the two sections were always meant to be one, say so once, in the Framework.

`lpc` raised this at Doc_06 §5 item 8 (Round 1's M3) and has carried it open since.

## 3. The World Profile template's Section 4 predates the M4 lens spine

`L4-Templates/World_Profile_Template.md` Section 4 names **four** required Ecological Summary dimensions — Emotional, Philosophical, Authority, Boundary — reflecting the lens structure that predates the **M4 Change Order of 2026-07-27**. Doc_07 is built on M4's **nine-lens** spine. Every M4-era world's Doc_07 therefore yields the same mismatch when its World Profile is written.

**Five worlds have a Doc_07** — Alexandria-Catechetical-School, Donatism, Imperial-Juridical-Christianity, Latin-Pastoral-Congregational-Christianity and Syriac-Christianity-Edessa-Nisibis — and every one of them meets this mismatch at Step 9.

**Already ruled, once, and not propagated into the template.** The project lead resolved this during the Donatism build — recorded verbatim at `World-Builds/Donatism/don_Decision_Log.md`, entry *"World Profile drafted, escalation on Ecological Summary scope resolved"*: **"cover all nine of Doc_07's actually-built lenses."** `don` and `lpc` both apply it. **The template still says four**, so the next world to reach Step 9 will hit it again and, if it does not know the ruling exists, will resolve it by build-thread judgment — which is what Donatism's own Round 1 review found and called wrong.

**Two further staleness findings in the same template**, both established at source by `lpc`'s Round 2 review:
- The template sources its own 4D Boundary Structures to **Doc_07 Section 2D**; under M4 it is **§2H**.
- The template's Doc_07 citation loci for lens content and for the Integrative Observation are stale against Doc_07's current structure (`§2A`–`§2I`; top-level `§1`–`§8`).

**What a coach thread should do:** write the standing ruling into the template so it is not re-litigated per world, and correct the stale Doc_07 loci.

## 4. A portfolio-level ruling filed inside one world's build folder — and the portfolio record it supersedes

**Added 2026-09-16, after the original three.** Not a defect in a governing file: a ruling that belongs in one and is currently nowhere near it.

**The project lead ruled on 2026-09-16** that Article 3 permits gapped formation-types, and adopted a four-limb methodological test (both-sides independence; phase testing substituting for cross-strand testing; the bridging disqualifier; the interval disclosed rather than filled). The ruling's own closing words: *"This ruling is portfolio-level and binds every gapped candidate… and belongs in the build methodology rather than in the Constitution."*

**It is recorded at `World-Builds/Latin-Pastoral-Congregational-Christianity/lpc_Decision_Log.md`, which is one world's log.** A build thread cannot file it anywhere else. **A ruling that binds every gapped candidate, filed only inside the first world that needed it, will be re-derived by the second** — which is the failure this handoff exists to stop.

**Two actions, neither available to a build thread:**

1. **File the ruling and its test in the build methodology**, where a world reaching Step 0 or Step 1 will meet it. `lpc_Gapped_Formation_Precedent.md` records `world-build-docs/_cross-world/` as the likely home for its own advisory text; the ruling has a stronger claim to a methodology file than the precedent does, because it is a standard rather than advice.
2. **Supersede the portfolio Step 0 Conclusion's own entry.** `CiC_Step0_Conclusion_FINAL_v2.docx` still logs this under *"Constitutional ambiguity flagged, not resolved"* — *"Article 3 … does not define whether a formation-type may recur across a temporal gap with a rival claimant contesting the interval."* **That is now resolved and the portfolio record still says it is not.** Until it is updated, the portfolio's own screening document contradicts a standing ruling.

**What does not need doing:** no Constitution amendment. The ruling turns on Article 3's own line — *"Boundary governance belongs constitutionally. Boundary evaluation belongs methodologically"* — so Article 3 already delegates this, and amending it would take back a delegation it deliberately makes.
