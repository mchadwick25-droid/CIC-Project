# Latin Pastoral-Congregational Christianity — Source Acquisition Manifest

**World:** `lpc` / Latin Pastoral-Congregational Christianity
**Produced at:** per-world build Step 2, Source Ecology, 2026-09-01
**For:** Mark, in his operational source-acquisition role — the point in this world's build where the project lead decides which editions enter `cic/texts/` before Phase A construction continues past Doc_02.
**Scope authority:** `Doc_01_World_Identification_Boundaries_Orientation.md` (Approved to proceed, 2026-09-01) — settled, not reopened here. Window c. 246–430 CE; Carthage and Hippo Regius, Latin-speaking Roman North Africa.
**Vendoring rule this manifest is built to satisfy:** `cic/texts/README.md` states plainly that the vendored library is public domain only — "Every file here must be out of copyright, and its own provenance header must say so… In-copyright editions… are referenced by `source` record and never vendored — committing them would be redistribution." Every item below is sorted by whether it clears that rule, not by how useful it would be if it did not.

**A note on this world's own starting position, unlike the sibling Donatism build's own manifest.** This world already holds an unusually complete primary-source base: the full ANF05 volume (Cyprian's own *Epistles*, treatises, and Pontius's *Life*) and eight full NPNF volumes of Augustine's own corpus are already vendored and already carry `confidence: assigned` for nearly every entry in the corpus map. This manifest is therefore short — it names real gaps at the *critical-edition* and *alternative-source* level, not gaps in primary-source coverage itself, which this world does not have in the way most other confirmed worlds do.

## 1. OPEN requests — public domain, real acquisition candidates

Numbered G1–G2, this project's own convention for the individual requests inside a world's own Source Request Manifest.

**G1. Cyprian, critical Latin edition — Karl von Hartel (ed.), *S. Thasci Caecili Cypriani opera omnia*, Corpus Scriptorum Ecclesiasticorum Latinorum (CSEL) 3.1–3.3 (Vienna: Gerold, 1868–1871).** Public domain (1868–1871). This is the critical Latin edition underlying the already-vendored ANF05 English translation of Cyprian's *Epistles* and treatises (Registry row 1). An Internet Archive item hosting CSEL 3.2 (the *Epistulae*) was found by live web search this session: `archive.org/details/CorpusScriptoruEcclesiasticorumLatinorum3.2Cyprian`. Volumes 3.1 (the treatises) and 3.3 (spuria and indices) were not independently located at a specific URL this session — a further search is needed before either can move to a Destination. Registry row 39. **Destination if acquired:** `cyprian_opera-omnia-critical_hartel-csel3_1-3.txt` (or split by volume, if the delivered format requires it). **Value if acquired:** would settle any textual/edition-level question about the Epistles or treatises directly against the critical apparatus, rather than only against the 19th-century ANF English translation already vendored.

**G2. Pontius, *Vita Cypriani*, alternative critical editions — A. Harnack (ed.), *Das Leben Cyprians von Pontius* (Leipzig, 1913), and/or M. Pellegrino (ed.), critical edition (Alba, year not identified this session).** Public domain status not independently confirmed for either this session (Harnack 1913 is very likely public domain on age alone; Pellegrino's edition year is unknown and its status cannot be assessed without it). Neither located at a specific URL this session — named from a single WebSearch result summarizing modern critical editions of the *Vita Cypriani*, not independently corroborated by a second search or opened directly. Registry row 40. **Destination if acquired:** to be determined once a specific edition and URL are confirmed. **Value if acquired:** an alternative to, or a check against, the already-vendored ANF English translation of Pontius's *Life* (already vendored, Registry row 7) — lower priority than G1, since the primary text this world's own construction actually cites is already vendored and verified; this candidate would add critical-apparatus depth, not new primary content.

**A network-access limitation, disclosed rather than papered over.** This build session's outbound network access blocks direct fetch of the specific pages named above — archive.org and general web domains return an egress-blocked error when checked directly from inside this session, consistent with this project's own standing note in `cic/texts/README.md` that its build sandbox blocks every patristic text host. The "where" reference above (G1's archive.org item) is a real result returned by a live web search this session — a genuine title, publisher, series, and URL, not invented — but it has not been opened and inspected page-by-page from inside this session. Before treating it as ready to vendor: (a) open the link and confirm it actually delivers full text under free access, not a preview or a lending checkout; (b) once downloaded, follow the corpus's own vendoring steps — write a provenance header into the file stating its public-domain basis, per `cic/texts/README.md`, and run `python cic/engine/texts_registry.py --write-readme` after adding the `ENTRIES` row for it, so the census and this Registry's own corpus-map dependency stay in sync.
