# Latin Pastoral-Congregational Christianity — Source Acquisition Manifest

**World:** `lpc` / Latin Pastoral-Congregational Christianity
**Produced at:** per-world build Step 2, Source Ecology, 2026-09-01
**For:** Mark, in his operational source-acquisition role — the point in this world's build where the project lead decides which editions enter `cic/texts/` before Phase A construction continues past Doc_02.
**Scope authority:** `Doc_01_World_Identification_Boundaries_Orientation.md` (Approved to proceed, 2026-09-01) — settled, not reopened here. Window c. 246–430 CE; Carthage and Hippo Regius, Latin-speaking Roman North Africa.
**Vendoring rule this manifest is built to satisfy:** `cic/texts/README.md` states plainly that the vendored library is public domain only — "Every file here must be out of copyright, and its own provenance header must say so… In-copyright editions… are referenced by `source` record and never vendored — committing them would be redistribution." Every item below is sorted by whether it clears that rule, not by how useful it would be if it did not.

**A note on this world's own starting position, unlike the sibling Donatism build's own manifest.** This world already holds an unusually complete primary-source base: the full ANF05 volume (Cyprian's own *Epistles*, treatises, and Pontius's *Life*) and eight full NPNF volumes of Augustine's own corpus are already vendored and already carry `confidence: assigned` for nearly every entry in the corpus map. This manifest is therefore short — it names real gaps at the *critical-edition* and *alternative-source* level, not gaps in primary-source coverage itself, which this world does not have in the way most other confirmed worlds do.

## 1. OPEN requests — public domain, real acquisition candidates

Numbered G1–G3, this project's own convention for the individual requests inside a world's own Source Request Manifest.

**G1. Cyprian, critical Latin edition — Wilhelm (Guilelmus) von Hartel (ed.), *S. Thasci Caecili Cypriani opera omnia*, Corpus Scriptorum Ecclesiasticorum Latinorum (CSEL) 3.1–3.3 (Vienna: C. Geroldi filius, 1868–1871).** Public domain (1868–1871). **Corrected here from an earlier draft's false rationale:** this is *not* the edition underlying the already-vendored ANF05 English translation — ANF05's own introductory notice states its base text is Migne's, not Hartel's CSEL 3 — so acquiring it would add an independent, later critical apparatus alongside the vendored translation, not recover that translation's own source text. The editor's own forename is Wilhelm, not Karl (an earlier draft's error). **A second correction, this revision (Round 3's own M7): this section's own "value if acquired" claim — that Hartel's CSEL 3 "would add a critical apparatus this corpus currently lacks" — is true only if a reader is not told that Hartel's own 1868–71 edition has itself been superseded.** The current critical edition of the entire Cyprianic corpus is *Sancti Cypriani episcopi opera*, Corpus Christianorum Series Latina (CCSL) 3 (ed. R. Weber and M. Bévenot, 1972), 3A (ed. M. Simonetti and C. Moreschini, 1976), and 3B–3D, *Epistulae* (ed. G. F. Diercks, 1994–1999) (Turnhout: Brepols) — Registry row 58, added this revision. It is in copyright and not a public-domain acquisition candidate, unlike Hartel; it is named here so the project lead is not asked to spend acquisition effort on Hartel while believing it to be the modern remedy for a missing apparatus. Public domain still makes Hartel the only *acquirable* critical text at the level this Manifest can request, and it remains real, independent value on that basis — the correction is to the framing, not the request. An Internet Archive item hosting CSEL 3.2 (the *Epistulae*) was found by live web search this session: `archive.org/details/CorpusScriptoruEcclesiasticorumLatinorum3.2Cyprian`. Volumes 3.1 (the treatises) and 3.3 (spuria and indices) were not independently located at a specific URL this session — a further search is needed before either can move to a Destination. Registry row 39 (and row 58 for the CCSL comparison). **Destination if acquired:** `cyprian_opera-omnia-critical_hartel-csel3_1-3.txt` (or split by volume, if the delivered format requires it). **Value if acquired, restated accurately a second time:** a critical apparatus and an independent 19th-century edition to check the vendored Migne-based translation against, and the only edition at this level of rigor that is actually acquirable under this project's public-domain-only vendoring rule — not the edition underlying that translation, and not the current scholarly standard (CCSL 3, in copyright, consult rather than acquire).

**G2. Pontius, *Vita Cypriani*, alternative critical editions — A. Harnack (ed.), *Das Leben Cyprians von Pontius* (Leipzig, 1913), and/or M. Pellegrino (ed.), *Ponzio: Vita e martirio di San Cipriano* (Alba: Edizioni Paoline, 1955).** **Pellegrino's own year is corrected here (Round 2's own M6): a second WebSearch this revision identified it as 1955, superseding this candidate's own earlier "year not identified" note (Registry row 48 discharges the same correction; propagated here to match, per CO-022's *Naming and term propagation* rule) — a fix that had landed in the Registry but not, until now, in this operational document.** Public domain status now assessable for both: Harnack's 1913 edition is very likely public domain on age alone; **Pellegrino's 1955 edition is in copyright**, and is not a viable public-domain acquisition candidate — Harnack's is the only live half of this request. Neither located at a specific URL this session — named from a single WebSearch result summarizing modern critical editions of the *Vita Cypriani*, not independently corroborated by a second search or opened directly. Registry rows 40, 48. **Destination if acquired:** to be determined once Harnack's own specific edition and URL are confirmed. **Value if acquired:** an alternative to, or a check against, the already-vendored ANF English translation of Pontius's *Life* (already vendored, Registry row 7) — lower priority than G1 and G3, since the primary text this world's own construction actually cites is already vendored and verified; this candidate would add critical-apparatus depth, not new primary content.

**G3. Possidius, *Sancti Augustini Vita* (*Life of Augustine*) — Herbert T. Weiskotten (ed. and trans.), *Sancti Augustini Vita Scripta a Possidio Episcopo* (Princeton: Princeton University Press, 1919), Latin text with facing English translation.** Public domain (1919). Named here as arguably the strongest single acquisition candidate in this manifest, stronger than G1: Possidius was Augustine's own companion for decades and the author of the Augustine-side counterpart to Pontius's already-vendored *Life of Cyprian* — a real gap this world's own formation-narrative work (Doc_02 §4) currently carries with only one of its two anchor figures' own companion-biographies. It is also the underlying source, via NPNF's own editorial apparatus, for the Megalius/primate-of-Numidia identification Doc_01 §5 and §9 both already disclose as resting on an unvendored work. **The identifier is corrected here (Round 2's own H2, independently re-confirmed this revision by live web search): an earlier draft named `archive.org/details/PossidiusAug` as the text edition; that item is in fact a 2008 audio recording (narrated by Maureen S. O'Brien, delivered as MP3/M3U files), not a scanned book, and would not deliver text of any kind if acquired.** The actual Internet Archive item hosting the bilingual scanned text edition is `archive.org/details/sanctiaugustiniv00possrich` — *Sancti Augustini vita scripta a Possidio episcope*, confirmed this session by live web search to be the Weiskotten 1919 Princeton dissertation with revised Latin text, introduction, notes, and English version, and further corroborated by a Cambridge *Classical Review* citation of the same edition. A second independent source, the hosted transcription at `tertullian.org/fathers/possidius_life_of_augustine_02_text.htm`, corroborates the same translation's existence and public availability, though that domain is itself one of the patristic-text hosts this session's own network access blocks (see the note below) and was not opened directly. Registry row 45. **Destination if acquired:** `possidius_vita-augustini_weiskotten1919.txt`. **Value if acquired:** closes the one-sided formation-narrative gap named at Doc_02 §4 and §9, and would let this document independently verify the Megalius identification at its own source rather than only through NPNF's editorial note.

**A network-access limitation, disclosed rather than papered over.** This build session's outbound network access blocks direct fetch of the specific pages named above — archive.org and general web domains return an egress-blocked error when checked directly from inside this session, consistent with this project's own standing note in `cic/texts/README.md` that its build sandbox blocks every patristic text host (re-confirmed at Round 3: both `archive.org` and `csel.at` returned the same block from that review environment too). The "where" references above — **G1's archive.org item, and G3's `sanctiaugustiniv00possrich`** (corrected to this identifier this revision, Round 2's own H2 — see G3 above) — are real results returned by live web searches this session, genuine titles, publishers, series, and URLs, not invented, but neither has been opened and inspected page-by-page from inside this session. Before treating it as ready to vendor: (a) open the link and confirm it actually delivers full text under free access, not a preview or a lending checkout; (b) once downloaded, follow the corpus's own vendoring steps — write a provenance header into the file stating its public-domain basis, per `cic/texts/README.md`, and run `python cic/engine/texts_registry.py --write-readme` after adding the `ENTRIES` row for it, so the census and this Registry's own corpus-map dependency stay in sync.
