Round 8 changed method deliberately — instead of further spot-checks, it read all 24 source records end to end, extracted every standing rule (30 total), and checked each against every term record citing that source at claim level, producing a durable matrix (`reviews/Step3a_Review_Round8.md` section C) so the standing-rule question does not need re-litigating. **Result: the standing-rule application problem is closed** — no unswept sibling remains. Verdict: MINOR REVISION REQUIRED, with the reviewer's own note that a stricter reading (any jargon recurrence is substantial on principle) would be defensible.
