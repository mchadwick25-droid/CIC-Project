Data and citation

The current release

All of the tree's data sits in one public file. The current file is release 20, dated November 8, 2026.

It holds 301 movements and 579 links. Each release has a number and a date, so a citation can name the exact version it used.

Download the data

The same file sits at two addresses. Neither one sends you on to another address, so a script can fetch it straight away.

https://www.churchfamilytree.com/data/world-census.json

https://churchinconversation.com/data/world-census.json

IDs that never change

Every movement and every link has an ID. Once we publish an ID, we never change it or use it again.

If a link is removed or merged, its ID moves to a retired list in the file. That list gives the date, the reason and any replacement.

If a movement is renamed, its old address leads to the new page.

Each movement page's earlier address, on churchinconversation.com, still works. It sends you, in one step, to the same page here.

How to cite the tree

Name the release you used. These examples use real IDs and the current release.

The tree

From the Church Family Tree by Faithways Studio, Inc., release 20 (November 8, 2026), CC BY-NC 4.0. https://www.churchfamilytree.com

A movement

“Desert Monasticism.” Church Family Tree, Faithways Studio, Inc., release 20 (November 8, 2026). https://www.churchfamilytree.com/tree/desert-monasticism

A link

“Alexandrian Catechetical / Christian-Platonist Tradition gave rise to Desert Monasticism” (Contested). Church Family Tree, Faithways Studio, Inc., release 20 (November 8, 2026), link alexandria-catechetical--desert-monasticism. https://www.churchfamilytree.com/tree/desert-monasticism#alexandria-catechetical--desert-monasticism

A release of the data

Faithways Studio, Inc. Church Family Tree data, release 20 (November 8, 2026). CC BY-NC 4.0. https://www.churchfamilytree.com/data/world-census.json

A movement's ID is the last part of its page address. A link's ID joins the IDs of its two movements with two hyphens. A second link between the same pair ends in --2.

A link's address is either movement's page, then # and the link's ID. It opens the page at that link.
