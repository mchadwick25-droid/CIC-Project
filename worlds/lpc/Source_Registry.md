**The rule, stated once rather than maintained as a per-row list (an enumerated version drifts out of step with the table it describes — the same remedy already applied to the Manifest's own §3 list):** a row is flagged for priority second-opinion review when it is Confidence C or below **and** it licenses a claim this document actually makes (not merely a non-empty Licensed-For field, which can state a negative).
