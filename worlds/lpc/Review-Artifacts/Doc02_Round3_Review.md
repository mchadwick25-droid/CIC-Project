### M4. Row 43 rests a Boundary-Status conclusion on a rule it attributes to the Template, which the Template does not contain
`Source_Registry.md` line 55 (row 43); `Doc_02_Source_Ecology.md` line 17.

Row 43 (Letter XCIII), Verification Note: *"…rowed here separately, as Native to this world on its own terms… **consistent with the Template's own rule that Native is assessed by what a source is actually used for in this world's own construction**, not by whether it is also, correctly, native elsewhere."*
