# HIGH Findings

## H1 — Fabricated claim about `lpc_World_Profile.md`'s actual content

**Where:** §5, "Two findings this phase surfaced, recorded rather than fixed in passing," item 1:

> `lpc_World_Profile.md` cites its Representative-emergence feed as *"RCF v2.0 Phase One"* at two sites. **The governing framework is V3.2**; v2.0 is the *Notes template's* version, not the framework's. A citation error that survived five review rounds.

**What's wrong:** This is false. `lpc_World_Profile.md` contains exactly **one** occurrence of the string "RCF" in its entire 776 lines (line 7): *"**Feeds:** World Capsule Core (inhabited voice rendering); Representative emergence (RCF V3.2, Phase One)."* This is the correct citation — it already reads "V3.2," not "v2.0" — and it appears once, not "at two sites." The string "RCF v2.0" (in any casing) does not appear anywhere in `lpc_World_Profile.md`, and a search of the entire `worlds/lpc/` directory finds it in exactly one place: the target document's own claim about it. There is no second site, and there is no first site either — the World Profile has never made this error, at least not in the version ("Approved to proceed... 2026-09-19") the Ecology Assessment itself says it is grounded in.

**Why this is HIGH, not a paraphrase slip:** this is not an imprecise summary of a real defect — it is a specific, quotable, checkable claim ("cites... as... at two sites," "a citation error that survived five review rounds") about the exact wording of a sibling canonical document, and it does not correspond to anything in that document. CLAUDE.md names fabrication as "the single most serious governance failure this project recognizes," and while this instance is about the project's own paper trail rather than the ancient world, the project's own comparanda show this exact species of error — a specific, wrong citation claim about another document — drawing a HIGH/Medium-High finding when `rzg`'s Round 1 review caught it (the Consensus Tigurinus Force ID misattribution). The same standard applies here. A downstream reader (a builder revising the World Profile, an external reviewer checking this "finding" against the file) would go looking for an error that does not exist.

**Fix required:** Retract this finding entirely, or — if it refers to some other document or an earlier, uncommitted draft state the builder has independent evidence for — restate it with the actual location, the actual wording found, and confirmation the claim was checked against the current file rather than remembered from an earlier pass.

## H2 — Force-ID citation error in the Thinness Mapping's own governing paragraph

**Where:** §2, final paragraph:

> **Thinness mapping runs the other way too**, per Framework V3.2 Part Three. Doc_08 shows domains where the forces pressed so hard that depth is well-grounded even where sources are thin: recurring persecution and the Decian *libelli* system (Forces 1A-1, 2A-2) and epidemic disease (1A-4) bear directly on G1 and G2, so Datus's depth on *what a bishop owes a frightened congregation* is well-founded even where individual testimony is missing.

**What's wrong, checked directly against `Doc_08_Forces_Document.md`'s own Force Index (seventeen forces, all enumerated):**

1. **Force 2A-2 is not part of "recurring persecution and the Decian *libelli* system."** Doc_08's own heading for it reads: *"Force 2A-2: Epidemic disease — the plague of c. 249–262."* It is a different force from persecution, deliberately treated that way by Doc_08 itself — Doc_08 §7 calls it "**Deliberately isolated**... the plague connects to no other force in this matrix," precisely because it is *not* the same phenomenon as the Decian persecution (Force 1A-1) or the later Valerianic one (Force 2A-1). Bracketing it together with 1A-1 under "persecution and the Decian *libelli* system" misdescribes what 2A-2 actually is.
2. **Force "1A-4" does not exist.** Doc_08's complete Force Index runs 1A-1, 1A-2, 1B-1, 1B-2, 1B-3, 2A-1, 2A-2, 2A-3, 2A-4, 2B-1 through 2B-5, 3A-1, 3B-1, 3B-2 — seventeen forces total, with no 1A-3 or 1A-4 anywhere in the document. The epidemic-disease force the sentence is reaching for is 2A-2 — the same force it has just (incorrectly) filed under "persecution" one clause earlier. The sentence cites the same underlying force twice, under two different and both-wrong labels, and never cites the ID that is actually correct for it.
3. **The claim that this force "bear[s] directly on... G2" is not supported by Doc_08's own Interaction Matrix.** Doc_08 §6 lists G1's connected forces as "1A-2, 1B-2, 1A-1, 2A-1, **2A-2**, 3A-1" — so 2A-2 does bear on G1, as claimed. But G2's connected forces are listed as "1A-1... 1B-1... 2B-1... 2B-2" — **2A-2 is not among them.** The plague force is real and does ground G1's depth on pastoral answerability under shared crisis; it is not Doc_08's own basis for G2's depth, and the document does not have an independent basis for the G2 half of this claim.

**Why this is HIGH:** this is precisely the kind of defect a sibling world's own Round 1 review (`rzg_Representative_Ecology_Assessment_Theophilus.md`, per its own Status line) rated High/Medium-High when it occurred there — a Force ID cited for the wrong force, compounded by a claim about what that force grounds that the cited document's own Interaction Matrix does not support. It sits in the Ecology Assessment's single most load-bearing Thinness Mapping conclusion — the claim that Datus's depth on "what a bishop owes a frightened congregation" is force-grounded rather than merely inferred — and the citation supporting it does not hold up as written.

**Fix required:** Correct to "Force 1A-1 (persecution) and Force 2A-2 (epidemic disease) bear directly on G1" and either find independent Doc_08 support for the G2 half of the claim or drop G2 from this sentence.

## M3 — Doc_07 §2D is cited for a claim §2D's own text does not make

§1.1 states: *"Doc_07 §2D records that this world concentrates real rigour on the single question of sacramental validity without developing a broader interpretive apparatus."* Doc_07 §2D's own opening sentence reads: *"Three doctrinal bodies dominate. **Sacramental validity across the church's boundary (G6)** is argued at book length... **Grace and human incapacity (G7)** is the densest textual object in the world... **Conciliar authority (G5)** is two incompatible formulas..."* — i.e., §2D itself identifies *three* dominant doctrinal foci, not concentration on a single question.
