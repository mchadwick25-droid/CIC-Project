# Open Gaps — World (proposed code `wsyr`): Syriac Orthodox (West Syriac) Christianity

Started 2026-09-25, the library-stage build thread's own first session for
this world (Steps 0-2: Step 0 Movement-Scope Confirmation, Doc_01 World
Identification, Doc_02 Source Ecology), commissioned by the project lead
the same day ("world batch c"). Every gap below either surfaced during this
session's own work or was inherited unresolved from a pre-existing project
record and is carried forward here per this project's own append-only,
never-renumbered discipline (CLAUDE.md, "Track gaps and exceptions
explicitly").

1. **This tradition's own attested self-designation.** OPEN. Step 0 §1
   and Doc_01 §1 both flag that "monophysite" is avoided as inaccurate and
   "miaphysite" is used only as the correct modern scholarly descriptor,
   neither being this tradition's own historical self-name. Not located in
   any vendored source this session. A task for whoever next works the
   primary sources closely (most likely to surface in Severus's own
   letters or John of Ephesus's own narration).

2. **The Chronicle of Edessa's own corpus-map role.** OPEN, inherited.
   First raised in `worlds/_cross-world/NEEDS-RULING.md` (not by this
   build thread): whether a Chalcedonian, composition-era (c. 540s) civic
   chronicle documenting this world's own ground "from the rival side of
   451" belongs in this world's own bucket at all, and at what role
   (currently `context`, `provisional`). Doc_01 §5/§10 and Doc_02 §2 Table
   B/§8 name this explicitly and do not decide it. Cross-referenced:
   `worlds/_cross-world/NEEDS-RULING.md`, item on `chronicle-of-edessa`.

4. **The Zachariah Rhetor compilation's own book-by-book own-voice /
   opponent-voice tagging.** OPEN, new this session. Vendored
   (`zachariah-rhetor_chronicle_hamiltonbrooks1899.txt`) at a single
   whole-work `role: tradition, confidence: provisional`, with an explicit
   `authors_ruled` note (in the same staging file) stating this
   understates the real complexity: Books III-VI derive from a
   Chalcedonian author (Zacharias Scholasticus) reporting sympathetically
   on this world's own early figures; the surrounding books are an
   anonymous miaphysite-sympathetic continuator's own work (c. 569).
   Modern scholarship calls the whole compilation "Pseudo-Zachariah
   Rhetor" for exactly this reason. A book-by-book pass is needed before
   any individual passage from this file is treated as either this
   world's own voice or an opponent's. Not done this session.

5. **Strand-singular finding held provisionally, pending a test this
   session could not run.** Doc_01 §6 finds this world strand-singular
   (Severus's doctrinal-definition phase and Jacob Baradaeus's later
   institutional-survival phase read as sequential necessities within one
   movement, not parallel strands) but flags this more loosely than
   `syr`'s own triply-reviewed strand finding. The test that would confirm
   or overturn it — comparing Jacob Baradaeus's own theory of ordination
   authority against Severus's own — cannot currently be run: Jacob left
   no surviving writing of his own (Doc_02 §3), so the comparison would
   need to draw on Severus's own writing about ordination theory (not yet
   checked this session) or later secondary tradition about Jacob, not a
   primary text in Jacob's own words. Named as a real methodological
   constraint, not only as an unfinished task.

6. **Severus of Antioch's own doctrinal corpus is not yet vendored.**
   OPEN, and named as the single most consequential acquisition gap this
   session leaves open (Doc_02 §11 item 8, §12 item 8). What is vendored
   (Select Letters, Book VI) is genuine administrative correspondence in
   Severus's own hand, but this world's own doctrinal center of gravity
   (the Christological argument against Chalcedon) is not yet sourced in
   Severus's own words specifically — only reported and summarized via
   secondary characterization (Step 0 §1) and via John of Ephesus's and
   Zachariah Rhetor's own narration about him. Real, named PD-editions
   exist to close this (Severus's Cathedral Homilies, trans. Maurice
   Brière, Patrologia Orientalis, various volumes; Zacharias Scholasticus's
   own *Life of Severus*, trans. M.-A. Kugener, PO 2, 1907) but neither was
   independently verified against a real host this session — see the
   Source Readiness Dossier §3 for what is and is not yet confirmed.
   **What Mark would need to fetch by hand, if pursued:** confirm the
   exact archive.org (or equivalent) identifier and full volume/fascicule
   range for Brière's Cathedral Homilies translation (Patrologia Orientalis
   is a long-running series; Severus's Homilies span many PO volumes across
   several decades of publication, so per-volume PD-by-date status needs
   checking individually, not assumed uniform), and for Kugener's 1907
   *Vie de Sévère* (PO 2).

   vendored and not independently consulted.** OPEN, new this session.
   Volker Menze's *Justinian and the Making of the Syrian Orthodox Church*
   (2008), W. H. C. Frend's *The Rise of the Monophysite Movement* (1972),
   Greatrex/Phenix/Horn's *The Chronicle of Pseudo-Zachariah Rhetor* (TTH

   all named in the census's own pre-existing source list (Menze, Frend,

   (all are in-copyright, correctly excluded from `cic/texts/` under this
   project's own PD-only intake rule) and none was independently consulted
   this session — their own claims are relied on only where a vendored
   primary source or the census's own prior research independently
   corroborates them, never taken on their own authority alone. **What
   Mark would need to fetch by hand:** all four are ordinary in-print
   scholarly books/chapters, available via library or purchase — not an
   archive.org-style acquisition task.
