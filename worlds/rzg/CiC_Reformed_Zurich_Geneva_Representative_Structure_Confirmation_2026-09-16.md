## Question — Representative structure

**Presented:** "RZG is confirmed one world, two strands (Zurich/Zwingli→Bullinger; Geneva/Calvin→Beza), bridged doctrinally by the 1549 Consensus Tigurinus but never institutionally merged — Doc_01 §5 explicitly reserved the Representative-structure question for the project lead at this exact stage. Research just completed found: the governing L4 template's own default is one Representative holding all documented strands in one register-range, with a multi-figure/two-voice construction named only as a rare exception for 'communions that refused each other's we' — and the actual construction procedure that exception path points to doesn't exist anywhere in the repo (a real, unfilled methodology gap). No world in this project has ever built a multi-figure Representative. A sibling world with real strand complexity (Imperial-Juridical-Christianity) successfully used a single voice to hold plurality. RZG's own record shows the two strands recognizing and doctrinally converging with each other (the Consensus's own signatories: 'two reforms... arrived at language neither could disown') rather than refusing each other's 'we' — the specific condition the template names as the actual trigger for splitting into two voices. Should RZG pursue a single Representative holding both strands, or a multi-figure (two-voice) Representative reflecting the strand division directly?"

**Options presented:**
1. *Single Representative, both strands (recommended)* — "One Representative whose own formation and voice draw documented material from both Zurich and Geneva, holding the strand plurality within one register-range — matches the L4 template's own stated default, has real working precedent (IJC), and fits this world's own record of doctrinal convergence and mutual recognition rather than mutual refusal. Doesn't erase T1's own permanent institutional tension or the Author-Gravity asymmetry — those get held and disclosed within the one voice, the same way IJC held its own real complexity. The next decision (which specific candidate/synthesis embodies this) would be brought separately, as its own grounded 2–4-option package."
2. *Multi-figure Representative, two voices* — "A dedicated Zurich voice and a dedicated Geneva voice, reflecting the strand division directly — more faithful to the institutional half of this world's own architecture (T1's own permanent non-convergence), but pursuing this means building a construction procedure that doesn't currently exist in this project's own methodology, with no completed-world precedent to check the result against. This would itself need to be flagged as a governance/methodology gap before construction could proceed, not just a world-specific choice."
3. *Something else / need more discussion* — "Weigh this differently, ask a follow-up, or handle it another way."

**Selected:** Option 1, "Single Representative, both strands (recommended)."
