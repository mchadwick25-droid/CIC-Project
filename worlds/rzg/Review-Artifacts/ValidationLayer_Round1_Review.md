### Finding 1 — HIGH — Section 3's Balance Testing quotation attributed to Doc_07 §2E is fabricated; no such text exists anywhere in Doc_07 or this world's build

**Checked:** Section 3, Balance Testing: *"...while Ethical/Legal (§2E) is 'an unusually rich dimension for this specific world — one of the most directly evidenced lenses in Doc_07, not a thin add-on.'"*

A direct search of the entire `World-Builds/Reformed-Zurich-and-Geneva/` folder for the phrases "unusually rich," "thin add-on," and "most directly evidenced" returns zero hits anywhere except this Validation Layer itself. This is not a paraphrase presented loosely — it is placed inside quotation marks, directly attributed to "(§2E)," exactly the citation format this document uses elsewhere for genuine verbatim quotations (e.g., the correctly-quoted "ritual life is defined as much by subtraction as by practice" two bullets later). This is precisely the "fabricated/mis-transcribed quotation" failure mode Section 2 of this same document spends a full paragraph cataloguing as this world's own recurring defect (Doc_04, Doc_06, Doc_07 each caught on it once) — now recurring inside the very document whose job is to test for it.

**Why it matters:** This is the single most serious finding in this review. A Validation Layer that fabricates a quotation while testing Ecological Integrity is not a cosmetic slip; it is the exact defect class this world's build has spent eight prior documents catching and fixing, occurring in the one document that is supposed to have nothing left to catch. The underlying substantive point (Ethical/Legal is unusually well-evidenced, not thin) is true and independently supportable from Doc_07 §2E's actual text — but it must be stated as this document's own characterization, not dressed in a quotation that does not exist.

**Fix required:** Remove the quotation marks and either paraphrase Doc_07 §2E's own actual language accurately and without quotation marks, or quote a real, character-verified sentence from §2E directly if quotation is wanted.

### Finding 2 — HIGH — Section 4's Differentiation Testing reintroduces the exact Doc_01 §1/Doc_05 §6.3 misattribution that Doc_07's own Round 1 review already caught and fixed

**Checked:** Section 4, Lutheran Wittenberg bullet: *"...doctrinal ... and civic-political (Doc_01 §1; Doc_05 §6.3; Doc_07 §5 independently corroborate that this world's own republican city-council structure ... is 'the single sharpest structural contrast with the sibling Lutheran Wittenberg world' — Wittenberg's own reform proceeding through a princely territorial church rather than city-by-city civic disputation)."*

**Found:** Doc_07 §5 — the very document this Validation Layer cites as one of three independent corroborating sources for the quoted wording — explicitly documents that this precise misattribution was already found and fixed once: *"Doc_05 §6.3 already names the republican city-council structure... as 'the single sharpest structural contrast with the sibling Lutheran Wittenberg world'... the same underlying comparison Doc_01 §1 also draws, in its own words, without using this exact phrase. **Corrected at Doc07 Round 1 review, which found an earlier draft of this document had attributed the quoted wording itself to both Doc_01 §1 and Doc_05 §6.3, when only Doc_05 §6.3 actually contains it.**"* `rzg_Decision_Log.md`'s own Doc_07 entry and `Open_Gaps_Tracking.md` item 24 both confirm this was a genuine Medium finding, corrected in Revision 2. By listing "Doc_01 §1; Doc_05 §6.3; Doc_07 §5" together immediately before the quoted phrase, with no distinction drawn, this Validation Layer restates the identical error Doc_07 Round 1 review corrected — implying all three sources state the quoted wording when only Doc_05 §6.3 does, and when Doc_07 §5 itself says in so many words that Doc_01 §1 does *not* use this exact phrase.

**Why it matters:** This is a direct regression of a specifically-named, already-fixed defect, inside the one document whose job is to confirm this world's build history is clean going forward. It is also, ironically, exactly the kind of error Section 4's own text elsewhere treats as settled (the document correctly distinguishes Doc_01 §1 from Doc_05 §6.3 nowhere else in this sentence). This should be treated with the same seriousness this world's build has consistently given a "softer recurrence" of an already-caught error (compare Doc_08 Round 1's treatment of the G1/Cell-1B recurrence, itself named accurately two sections earlier in this same Validation Layer).

**Fix required:** Attribute the quoted phrase to Doc_05 §6.3 alone; cite Doc_01 §1 and Doc_07 §5 separately, without quotation marks, as sources that independently draw or corroborate the same underlying comparison without using this exact wording — matching Doc_07 §5's own corrected text exactly.

### Finding 3 — HIGH — Section 0's reliance on Donatism's prior Completion Standard verification is stale: the actual current file already contains a V1.4 Change Order that modifies Section C, the exact section this document says is "unaffected by any Change Order"

**Checked:** Section 0: *"...Donatism's own verification (that V1.1 through V1.3 each modify only Section B, leaving Section C, the section Framework V7.4 actually cites, unaffected by any Change Order) is fleet-level infrastructure work, not a world-specific finding, and this document relies on it directly rather than re-doing it."*

**Found:** Direct inspection of `reference/method/CiC_World_Build_Completion_Standard_V1.3.md` (the file this Section 0 says was "independently confirmed present this pass") shows it now opens with a **fourth, later Change Order note**: *"**V1.4 change (Change Order, Mark, 2026-09-14; recorded as a Change Order, never a silent edit):** section C is corrected — Relational Safety (Probe 11) tests the shared, portfolio-level Facilitator-handoff mechanism..."* This V1.4 note is dated 2026-09-14 — after Donatism's own Validation Layer verification (which found only V1.1–V1.3, all Section-B-only) and two days before this Validation Layer's own drafting (2026-09-16). The claim this document imports from Donatism — that Section C, the section Framework V7.4's Freeze Criteria actually cites, is "unaffected by any Change Order" — is therefore no longer true of the file as it currently stands, and this Validation Layer's own Section 0 does not disclose this. The note explicitly naming what changed ("Found while reconciling Donatism's own Phase Five record...") makes clear this is a real, substantive Section C amendment, not a cosmetic one. "Independently confirmed present this pass" describes only confirming the *file's own filename* is still V1.3 (true) and that no V1.0 file exists (also true) — not that its content still matches what Donatism verified.

**Why it matters:** This is exactly the risk the review brief asked to be checked directly: whether it is legitimate for this document to lean on Donatism's own prior verification without re-doing it. It is not fully legitimate here, because the fact Donatism verified has since changed, and this document's own Section 0 states the stale conclusion as though it were still current — understating, rather than merely disclosing, a real and currently-checkable risk. In this specific instance the practical consequence is limited (this world has no Representative and does not need Section C's Relational Safety gate yet), but the document's own reasoning — "this document relies on it directly rather than re-doing it" — is stated as a general methodological point, and as stated it is now factually wrong about the file it cites.

**Fix required:** Disclose the V1.4 Change Order directly: state that Section C has in fact been amended once since Donatism's own verification (by V1.4, correcting Relational Safety to a portfolio-level mechanism check rather than a per-world register test), that this amendment does not change the freeze-requirements text this world currently needs (no Representative exists, so Section C's Relational Safety gate is not yet in play), and that Donatism's own Section-B/Section-C verification is accordingly current only through V1.3, not through the file's actual present state. Reliance on a fleet-level check performed by a sibling world is reasonable in principle; stating its conclusion as still true of the current file without checking is not.

### Finding 5 — MEDIUM — Section 3's Complexity Testing overstates what Doc_07's Integrative Observation (§6) itself "states directly" about T1 and T2

**Checked:** Section 3, Complexity Testing: *"Doc_07's own Integrative Observation (copied verbatim into the World Profile, Section 10) states directly that neither the T1 nor T2 tension was closed by this world's own record..."*

**Found:** Doc_07 §6's Integrative Observation is an inhabited-voice, cross-strand passage (marked "[Inhabited — cross-strand, holding both voices at once, per Article 23]") that never names "T1" or "T2" and never states, propositionally, that either tension remains open. Its actual closing lines are poetic rather than declarative: *"What that page could not do, and did not try to do, was make our two councils one, or our two ways of testing what we believe the same way. We remain what we always were: one faith, arrived at twice."* This gestures at T1 (the councils not made one) but does not name or address T2 (the Supper's own synthesis-versus-diplomacy contest) at all in explicit terms — it reads, if anything, as being about the authority-structure/formation-mechanism divergence, not the Eucharistic-doctrine tension specifically. The actual explicit statement that neither tension is closed lives elsewhere — Doc_07 §7 ("The Consensus Tigurinus's own [CT] contest, carried forward again, not adjudicated here") and §2I ("T1 and T2 are not exceptions to this formation logic; they are what the ecology actually lived rather than resolved") — not in §6 itself.

**Why it matters:** This is a real, checkable overstatement of what a specific, quotable passage actually asserts, in the section of this document whose entire job is precise, source-grounded restatement. The underlying finding (both tensions remain open) is true and well-supported elsewhere in Doc_07 — the defect is attributing that explicit statement to a passage that does not make it explicitly.

**Fix required:** Either cite Doc_07 §7 and §2I (where the "neither tension is closed" finding is actually stated directly) alongside or instead of §6, or reframe the §6 reference to describe what the Integrative Observation actually does — holds both strands' voices together without resolving their divergence into one — rather than claiming it "states directly" a finding it only gestures toward.

### Finding 6 — LOW — Section 3's Emergence Testing "flagship insight" compresses two distinct Doc_07 §5 findings into one, without disclosing the compression

**Checked:** Section 3, Emergence Testing: *"Doc_07 §5's own flagship insight — that this world can be doctrinally unified and institutionally divergent at the same time, and that the same genre-asymmetry pattern surfaces at three separate lens scales as one underlying cause rather than three unrelated caveats — was arrived at only by holding multiple lenses together..."*

**Found:** Doc_07 §5 ("Cross-Lens Synthesis") states three separate, individually-numbered findings ("First:... Second:... Third:..."), not one. The "doctrinally unified and institutionally divergent" claim is §5's *first* finding; the genre-asymmetry-at-three-scales claim is its *second*, entirely separate finding. Presenting both under a single "flagship insight" label is not inaccurate as to content — both are genuinely cross-lens findings not visible from any single lens — but it does blend two of §5's three numbered findings into one without disclosing that this is a compression rather than a direct restatement of "the" flagship finding. (This exact "flagship insight" framing and sentence structure also appears, nearly verbatim in shape, in Donatism's own `don_Validation_Layer.md` Emergence Testing bullet, applied to Donatism's own §5 findings — suggesting this is a reused template phrase rather than a claim this document means as a literal quotation from Doc_07.)

**Why it matters:** Minor and cosmetic — no fabrication, no misattribution, and the underlying substance is accurate. Worth a precise fix only because this document's own standard, applied to itself, is exact restatement rather than compression presented as a single finding.

**Fix required:** Optional. If revised, either present the two findings as "Doc_07 §5's first and second findings" rather than one undifferentiated "flagship insight," or keep the combined framing but note explicitly that it draws on two of §5's three numbered findings.

This Validation Layer does the synthesis job Construction Step 9 requires competently across most of its ten sections and correctly declines to introduce fresh research. **Escalation categories:** none apply to this review's own findings. This is ordinary citation-fidelity and sourcing-precision correction work, fixable directly by the build thread, matching the discipline already applied at every prior document in this world's build (Doc_04 through the World Profile).
