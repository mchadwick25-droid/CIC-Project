# Doc_04 — Gravity Discovery Template

**Version 1.0. Companion to Construction Framework V7.3, Part III (Step 4: Gravity Discovery). Filed in reference/L3B-World-Build-Methodology alongside the Formation World Template, the Representative Permanent Prompt Template, and Doc_02B's Approved Source Database Template. Authored by the coach thread, per the OneDocAtATime Build Protocol's assignment of editing authority over L3B/L4 templates to the coach role. This is the first L4 template Doc_04 has ever had — every world built before this one (World #1, World #3, World #7, World #9) produced its own Doc_04 without one, each inventing its own structure independently.**

---

## Why this exists

A coach thread comparing Doc_01–04 across four completed worlds (World #1 Post-Apostolic House-Church, World #3 Desert Monasticism, World #7 Syriac Christianity, World #9 Hieronymian Ascetic-Literary) found that Doc_01, Doc_02, and Doc_03 — each governed by an existing L4 template — converge on recognizably the same structure across every world: same section order, same section names, same required moves in the same place. Doc_04, which the Construction Framework itself already flags as lacking a template ("the least structurally supported step in the pipeline," a description every one of the four worlds' own Doc_04 repeats near-verbatim), does not converge at all. Section counts across the four range from 6 to 9. No two worlds use the same section names beyond "Interaction Matrix." Only one of four worlds gives the Confidence/Gravity Cross-Check and the Forces test their own dedicated sections; the other three embed them as inline fields inside each candidate's own paragraph, with no way to confirm from the table of contents alone that every candidate actually received both checks. Only one of four worlds explicitly revisits Strand Determination as its own titled section — one other world does the equivalent reasoning but buries it inside a single candidate's row, where it is easy to miss despite being, by that world's own reviewers' account, the single highest-stakes judgment in the document.

This divergence has a real cost, independent of whether any given world's actual gravity classifications turned out sound (in all four cases examined, they did, after review). Each world's Doc_04 review history caught a different class of error, and the class tracked the structural choice each build thread happened to make: the world with the most explicit cross-referenced structure caught a self-contradiction that survived a full "fixed" revision cycle; the two worlds that chose to maintain a companion spreadsheet each caught that spreadsheet silently drifting out of sync with the narrative it was supposed to mirror; the two worlds with no companion spreadsheet had no such failure but also no easy way to look anything up without reading the whole document. None of this reflects the four worlds themselves being differently rigorous — it reflects four different ad hoc disciplines, each carrying its own blind spot, where one shared discipline with a known, patchable weakness would serve every world better.

## Governing constraint on this template — read before using it

**This template governs where a required check lives and whether it happened. It never governs what the answer is.** Per the Formation World Template's own Template Flexibility Principle and Dimensional Weighting Principle — "the goal is consistency of exploration rather than uniformity of outcome" — nothing below may be read as requiring two worlds to reach the same kind of conclusion, use the same number of candidates, or weight any dimension the same way. If a requirement in this template ever seems to push toward a substantive outcome rather than a structural one, that requirement is wrong and should be flagged back to the coach thread for correction, not followed.

Concretely, this template does **not** constrain:
- The number of candidate gravities generated, tested, or advanced.
- Which candidates reach Primary, Supporting, or Tensional, or the reasoning used to get there.
- The length or depth of any section (Template V1.5's Evidence Proportionality Principle governs this, as it does everywhere else).
- Whether Cross-Strand Gravity testing runs in its standard form or a declared, justified substitute (a world found strand-singular at Doc_01 needs a different discipline than a strand-plural world, and that difference is a finding, not a deviation to correct).
- Prose style, or whether a world chooses to embed the Cross-Check and Forces test inline per-candidate or pull them into dedicated collective sections. Both layouts satisfied this template's actual concern (see Section 4 below) equally well once the required index table exists.
- Whether a companion workbook is used at all.

## Required structure

### 1. Candidate Gravity Generation

Required section. States the method by which candidates were generated. The only structural requirement: every candidate traced to a specific, named Doc_02 and/or Doc_03 evidence stream, not general impression or period-familiarity. No fixed count.

### 2. Candidates Considered and Not Advanced

Required section, even if empty (state plainly that none were considered and set aside, if that's true). This closes the one gap where a plausible-sounding candidate could be silently dropped rather than named and reasoned through. Three of the four worlds examined already do this by their own initiative; this makes it a checked requirement rather than a matter of a build thread happening to remember.

### 3. Per-candidate testing

Free-form. Each candidate is run through the six gravity tests (Repetition, Dependency, Formation, Explanatory, Persistence, Interaction), the Confidence/Gravity Cross-Check (Framework Part III), and a forces-connection notation (Forces Framework Step 4), in whatever prose structure and depth the evidence actually warrants. No template control over how these are written, how long they run, or which get more attention — that's exactly the kind of dimensional weighting the Formation World Template protects.

### 4. Classification Summary — with a required index table

Required section stating each candidate's final classification (Primary/Supporting/Tensional/did-not-reach-gravity-status) with reasoning, in whatever form the build thread judges best. In addition, this section must include one summary table, covering every tested candidate, with these columns:

| Candidate | Six-Test verdict | Confidence/Gravity Cross-Check result | Cross-Strand (or declared substitute) status | Classification |
|---|---|---|---|---|

This is the actual fix for the "hard to verify" problem found across all four prior worlds — not by forcing every world into one prose layout, but by guaranteeing one place a coach or downstream builder can go to confirm, without reading the full document, that every candidate actually received every required check and where its testing lives if they need the full argument.

### 5. Cross-Strand Gravity testing (Constitution Article 21) — or a declared, justified substitute

Required to be present in some form. If the world's own Doc_01 found strand-plurality, this runs in its standard cross-strand form. If Doc_01 found strand-singularity (as World #9 did), this section must instead name the substitute discipline actually used and argue explicitly why it serves the same purpose Article 21 testing would — World #9's substitution of bipolar-geography testing for its Rome/Bethlehem structure, run because a gravity visible only at one pole would raise the same "artificially unified ecology" concern cross-strand testing exists to catch, is the model example of a legitimate, disclosed substitute. What this template will not accept is silent omission of the whole discipline.

### 6. Interaction Matrix

Required, full pairwise coverage across every tested candidate. This is the one structural element all four prior worlds converged on independently even without a template; this section simply codifies existing good practice rather than changing it.

### 7. Open Items Carried Forward

Required. Anything this document could not close — a confidence divergence, an unresolved tension flagged for Doc_05/Doc_08, a proportionality concern about which gravities center which voices — is named here explicitly rather than silently absorbed into a clean-looking final classification.

### 8. Companion workbook (optional)

A build thread may maintain a separate spreadsheet index alongside this narrative document, or may not — both are compliant. If one is used, it must carry a single explicit line stating the date or commit it was last confirmed synced against the narrative document. This is a direct, minimal countermeasure to the specific failure mode observed in two of the four prior worlds (a companion workbook silently drifting out of sync with an already-corrected narrative), without requiring any world to build one that doesn't need it.

### 9. Document Log

Required, per the OneDocAtATime Build Protocol's own file-saved-review discipline: every review round, whether it was saved as its own file, and what it found.

## What this template deliberately leaves unsettled

This is a V1.0 draft, built from a four-world sample. It has not yet been tested against a live build the way Doc_02B's V1.0 was tested and then substantially reworked after real use surfaced problems this document's author couldn't have anticipated from comparison alone. Flag anything that turns out to force a substantive outcome, or that a world's genuine evidentiary shape doesn't fit, back to the coach thread rather than working around it silently — that's exactly the kind of finding a V1.1 revision should be built from, not a reason to abandon the discipline this version establishes.
