**Step:** S3.3 — R4/R5: ID-keyed session exclusion set + MMR; sentinel
typed-nulls; relevance floor. **Date:** 2026-07-27.

## The change (Touches as declared)

- `state.py`: `surfaced_chunk_ids` — per-world lists of chunk ids surfaced
  this session (the conversation-state change that triggers the safety
  rerun below).
- Both retrievers: deterministic exclusion of surfaced ids at candidate
  stage, each exclusion logged in the audit trail;
  `_prepare_representative_turn` passes the set in and records what each
  turn surfaces.
- `partition_tier1_short_circuit`: the `already_discussed` substring proxy
  is **deleted** (it measurably failed on composite labels — the
  B-RETR-documented composite-Term gap), and — anticipating R6's own
  stated rule — a candidate carrying a *genuinely evaluable*
  Do-Not-Retrieve-When never short-circuits past its own guard
  (retired-class clauses don't count as evaluable).
- Story vote: the "already told earlier" instruction removed — already-told
  is now structural, not judgment.
- Indexers: em-dash/dash sentinels in condition fields normalize to typed
  nulls at parse time (all 12 stores rebuilt).
- `hybrid.py`: adaptive dense relevance floor (absolute cap or
  best-distance + margin — an absolute floor measurably cut a must-doc
  0.2 behind the best hit on a long reactive query) and MMR re-ranking
  *within* the candidate window at λ=0.85 (0.7 demoted a genuinely
  distinct sibling doc as a duplicate; global MMR displaced a must-doc
  out of the window — both caught by the harness, both fixed before
  commit).
- Harness: de-dup cases gain `surfaced:` — the runtime-state input the
  new mechanism reads (a real session would have recorded those ids when
  the case's context transcript happened). The de-dup category now tests
  "is the deterministic exclusion honored end-to-end," replacing "can the
  substring proxy catch it" — which it measurably could not.

## G — the win conditions (delta committed: `baselines/retrieval_post_S3.3.json`)

| category | baseline violations (retrieve/skip) | now |
|---|---|---|
| **de-dup** | 12 / 5 | **0 / 0 — all six worlds, both policies** |
| **negative-condition** | 12 / 6 | 16 / **0** |

- De-dup is closed outright: the exclusion set removes the duplicate from
  the candidate set before any ranking or voting sees it.
- Negative-condition **skip-bracket violations are zero everywhere**: no
  candidate ever bypasses its own guard again. The retrieve-bracket rise
  (12→16) is the same fact viewed pessimistically — *more guarded docs
  now reach the vote at all* (previously the tier-1 short-circuit sailed
  past their conditions), and the all-votes-retrieve bracket counts every
  one. The real system sits between the brackets; the vote those docs now
  receive is exactly what evaluates their guards.
- **The bracket widened by design** (34 of 42 regression cells vs B-RETR
  are skip-bracket cells): every guard now hangs on the vote instead of
  being bypassed. Per the harness's own framing, bracket width measures
  "how much hangs on the LLM vote R6 replaces" — S3.4's cross-encoder +
  retained-DNRW-vote is the designed narrowing, and this measurement is
  its baseline.
- Residual non-bracket regressions (8 cells): the reactive-turn class
  (Alexandria/Desert — S3.5's R9 query rewriting, already those steps'
  named targets) and the three worlds' negative-condition retrieve-bracket
  cells (S3.4).
