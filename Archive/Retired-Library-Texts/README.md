# Retired Library texts

Texts that were vendored into `cic/texts/` and are retired from it. Nothing here is read by the program.

## augustine_epistulae-praefatio-indices-lat_goldbacher-csel58.txt

Alois Goldbacher, ed., Augustine's *Epistulae*, Pars V (praefatio and Indices I-VI), CSEL 58, Vienna and Leipzig, 1923. It holds no letter text.

The scan behind the file (Internet Archive item `corpusscriptorum58auguuoft`) is a facsimile printed by the Johnson Reprint Corporation in 1961. Its own title page says "Reprinted with the permission of the original publishers" and "First reprinting, 1961". The file's header records the rights basis as the 1923 publication date, which does not cover the 1961 reprint. The Library excludes the 1962 Johnson Reprint facsimile of CSEL 33 on the same ground. No other public scan of CSEL 58 exists on the Internet Archive, so the volume is not vendored.

`augustine_epistulae-praefatio-indices-lat_goldbacher-csel58.yaml` is the corpus-map staging file that assigned the text to the Latin pastoral and congregational shelf.
