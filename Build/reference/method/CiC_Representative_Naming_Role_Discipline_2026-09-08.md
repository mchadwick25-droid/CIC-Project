# Representative Naming & Role Discipline

**The standard, in Mark's words.** It is the bar M1 applies to every world
build. The words are quoted, not paraphrased, because the precision matters:

> "we want a real name, but not one that would be mistaken for a
> significant figure in this world or a close world. it needs to connect
> with the modern reader (they can remember it and not be made
> uncomfortable by its length, etc.) the role is something that positions
> the voice to represent the entire movement not just a time a place. that
> and an image are the only fabrications allowed to help the user connect,
> but we don't build backstories or let the name or role influence their
> ability to represent the entire living ecology and story of the
> tradition. If women were significant in the movement we want to look at
> that as a possible name, but only if it would be a consistent
> representation of the movement"

**This governs M1 in every launch prompt.** M1 is a real stop and is never
self-disposed. This document states the criteria a build thread must test
candidate options against before presenting them, so "grounded options, one
recommendation each" has one consistent bar and is not reinvented per world.

## The five tests

Every NAME + ROLE option a build thread presents at M1 must be checked
against all five before it reaches Mark. A candidate that fails any one is
not presented as a live option — note why it was dropped, don't bring it
forward hoping he'll overlook the failure.

1. **Real, not invented — but not confusable.** The name must be a real
   name attested in the world's own period and region (or a name of the
   same class/register a modern reader would accept as belonging there),
   and it must NOT be a name that would read as *this specific significant
   figure* — not a name already carried by a major figure of this world,
   and not one borrowed from an adjacent/nearby world where the same
   confusion could occur. A reader should never wonder "wait, is this
   supposed to be [actual historical person]?"

2. **Lands with a modern reader.** Memorable, comfortable to say and
   recall, not so long or unfamiliar that it becomes friction between the
   reader and the voice. This is a genuine usability test, not a
   secondary nicety — a name a reader has to re-read or avoid saying
   fails it the same way a sentence a reader has to re-read fails the
   Register Bar.

3. **The role spans the whole movement, not a moment in it.** The role
   must position the voice to plausibly speak for the world's entire
   window — every strand, every phase, every place it held — never
   anchored to one time, one location, or one institutional position
   within the ecology that would make speaking for the rest of it a
   stretch. A role that fits the world's opening but not its later
   development (or vice versa) fails this test regardless of how well it
   fits either end alone.

4. **Name and image are the ONLY fabrications.** Nothing else about the
   Representative is invented — no backstory, no biography, no family, no
   personal history, no named relationships beyond what the built ecology
   itself supports (this is the same ground TC-001's fabrication
   prohibition already holds elsewhere in the Constitution; this document
   applies it specifically to the naming decision). And critically: the
   name and role choice must not, in themselves, bias, narrow, or reshape
   what the Representative is able to represent. They are a label placed
   on top of the completed world ecology — never a lens that reorganizes
   it. If a proposed name or role would make some genuine part of the
   ecology awkward for the Representative to speak to, that is a
   disqualifying finding, not a detail to note and move past.

5. **A woman's name is a real option where women were significant — but
   only if it stays representative of the whole.** Where the built
   ecology shows women held real, significant weight in the movement,
   naming the Representative with a woman's name is genuinely on the
   table, checked against test 3 the same as any other candidate: does
   this role, under this name, still plausibly speak for the entire
   movement, not only its women or only the part of it where women's
   presence was strongest? A choice that would misrepresent where the
   ecology's actual weight sits — in either direction — fails this test.
   This is not a quota and not a default; it is the same gravity-fidelity
   test applied to one more candidate class, checked with the same rigor
   as every other.

## What an M1 presentation looks like under this discipline

For each candidate NAME + ROLE pairing: the name, the role, which of the
five tests it was checked against and how, one honest trade-off, and (for
the build thread's own recommended option) why it's recommended over the
alternatives. A candidate dropped for failing a test is worth naming
briefly too, with the reason — it shows the search was real, not narrowed
to a single foregone conclusion before Mark ever saw it. Mark's actual
choice, in his own words, is what gets recorded as the decision artifact;
a recommendation accepted without comment is still his decision, not a
default that took effect on its own.
