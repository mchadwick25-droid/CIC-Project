# Build skills

The six CiC build skills, written for Process V2.0:

- `cic-build-cycle`: the one-document-at-a-time cycle, review rules, gate layer, escalation, disposition.
- `cic-lexicon-index`: Doc_03 and Doc_06 lexicon terms and their lookups.
- `cic-gravity-index`: Doc_04 Gravity Discovery.
- `cic-forces-index`: Doc_08 Forces Document.
- `cic-story-repository`: Doc_09 Story Inventory.
- `cic-validation-suite`: Ecology Assessment, probes, Deep Interview, freeze checks.

Each `SKILL.md` is the single source for its skill. A change to the process is made here, once, and every thread reads it from here.

To load a skill, a thread reads `Build/reference/method/skills/<skill-name>/SKILL.md` before it starts that kind of work. Start with `cic-build-cycle`, then read the skill for the document at hand.
