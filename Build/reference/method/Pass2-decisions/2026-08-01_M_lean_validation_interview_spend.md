# Lean validation at interview-class spend; table on limited use

**Decision:** the quality checks a world needs run at interview-level API
spend, because API credit use is too high. The multi-representative table is
on limited use to manage expenses. Conversation dynamics are later work; the
right things said come first.

**Scope:** conversation dynamics count for interviews, but not as much for
multi-representative table dynamics. So the bar for a freeze is content
accuracy AND single-representative interview dynamics (parroting, pushback,
over-settling, re-gloss, cross-round memory, register, ceiling behavior
— pressed by an extended 6–8-round live interview plus targeted probes);
ONLY multi-representative table dynamics are deferred. Freeze
declarations read "content-and-interview-frozen; table-dynamics
deferred."

**Policy, as recorded in the Record-Native World Build Process V1.0
(§5) and its launch prompt:**

1. **Content accuracy is the bar for a freeze** ("the right things said");
   live conversation dynamics are deferred work, not freeze blockers.
2. **Lean validation is the DEFAULT for future world freezes:** the free
   deterministic floor (7 gates, schema, render parity, prompt coverage,
   grep-clean demos — plus the record store's by-construction
   anti-fabrication) + ~8–12 single-trial targeted probes concentrated
   on the classes that historically caught real defects
   (naming-collision, horizon press, thinness-aimed fabrication press,
   re-gloss check, world-specific REQUIRED probes), blind-graded + ONE
   live 3-round Deep Interview against the real deployed site (which is
   also the deploy verification). Interview-class spend: ~$1.25–1.80
   measured, vs ~$30 for a full battery.
3. **The full V7.4 two-trial battery runs only on the project lead's instruction.** This is
   a recorded project-lead deviation from CF V7.4's own two-trial
   Validation Protocol Rigor text; reconciling the Framework wording is
   a coach-thread item (process doc Appendix C).
4. **The multi-representative table is on LIMITED USE; the TRR is
   DEFERRED by default.** When table work re-opens, the standing
   cost-capped form applies (cap 3; sample 2–3 sharpest pairings —
   `S6.2_M_table_cap_and_trr_cost.md`). B-7a pairing disciplines are
   still authored in full; they are just not live-pressed at freeze.
5. **Declared, never silent:** a lean freeze declaration reads
   "content-frozen; table-dynamics deferred" and names what lean gives
   up — the second trial's variance detection (mitigation: the cheap
   live re-probe pattern on any user report — the Chloe precedent) and
   live-pressed table dynamics.

**Context:** the six S6.2 freezes ran the full battery + TRR (PAHC
battery ~$30; a credit exhaustion killed a TRR table mid-run once). A
August 2026 live Deep-Interview sweep demonstrated the fundamentals and
content-accuracy re-probes verifiable at $1.25–1.80/world against the
real deployed site. Intro pricing (claude-sonnet-5, $2/$10) ends
at the end of August 2026; measured figures rise ~50% after.
