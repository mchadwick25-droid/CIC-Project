# M2 — First migration world (Pass 1 §12.5) — DECIDED

**Decision:** the blueprint §2.1 proposal, adopted as proposed — **Desert
Monasticism migrates first.** Smallest record count (9 terms, 8 stories —
fastest schema shakedown), worst live-fabrication record (highest safety
value per record), smallest new-authoring load. Alexandria's
retrieval-economics win arrives with R7 regardless of migration order.

**Alternatives considered:** (1) Alexandria (largest R7 win unlocked
earliest; heaviest shakedown — 45 Tier-1 terms); (2) Syriac (best-documented
defect trail; already pinned by B-RETR regression cases). Both declined in
favor of Desert Monasticism.

**Unblocks:** Phase 2 (S2.1–S2.9) against `wrs/records/desert_world/`;
completes Phase 1's exit criteria alongside M1.
