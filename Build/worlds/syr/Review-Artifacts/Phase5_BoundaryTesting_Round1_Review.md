## 1. Citation accuracy

However, several citation problems were found, one of them serious:

**1a. A fabricated quotation attributed to Part Eight's own governing text (RS-3, Section 3.6).** The RS-3 result reads: *"deliberately scored so, to make the exact point Part Eight's own governing text warns about: 'a system tuned only against frame-breaking and self-referential probes risks learning to suppress the very disclosure Article 33 requires.'"* This sentence, presented in quotation marks as if lifted from the governing text, **does not appear anywhere in Section 2.1's own verbatim reproduction of Part Eight**, nor in Section 2.2's verbatim reproduction of Facilitator-Governance V3.4 §15 — the only two governing-text blocks this document itself reproduces. Section 2 states explicitly that "the governing framework text is not paraphrased or reconstructed from memory. It is reproduced in full below, exactly as supplied for this build." This quotation violates that discipline: it is either an invented sentence dressed up as a verbatim citation, or a real sentence from somewhere else in the Framework that has been misattributed to Part Eight and never actually shown. Either way, the document's own stated citation practice is not honored here. The underlying analytical point (a single illustrative exchange cannot validate a system-level escalation requirement) is sound on its own merits and does not need this fabricated prop — but the fabrication itself is a real defect that should not survive to a clean draft.

**1b. A misquote inside quotation marks (SE-2, Section 3.8).** SE-2 states: *"Turn 1 correctly holds Formation Calibration Section 2.3's own hedge ('real but narrow... a thin, largely nineteenth-century citation web,' Doc_02, Section 11)."* Formation Calibration §2.3's actual wording, verified directly, is *"real but narrow, resting on a **small**, largely nineteenth-century citation web."* Phase Five's rendering silently substitutes "thin" for "small" while keeping the quotation marks — a paraphrase presented as an exact quote. Minor in substance, but exactly the kind of drift this project's own discipline (see Ecology Assessment's own Revision Log, which caught and fixed comparable splicing) is designed to catch.

## Overall verdict: SUBSTANTIAL REVISION REQUIRED

The large majority of this document is careful, well-sourced, and does real work rather than merely gesturing at Part Eight's requirements — the probe design, the Persian-anchor discipline, the C4 boundary handling, the firewall, and most individual citations all hold up under adversarial scrutiny. But per this project's own standing rule (substantial = changes to a claim's substance, confidence, sourcing, or scope boundary — not mere wording), the following must be fixed before this document should be considered ready for the next stage:

1. **Remove or properly source the fabricated quotation in RS-3** ("a system tuned only against frame-breaking and self-referential probes risks learning to suppress the very disclosure Article 33 requires"). This sentence does not appear in either verbatim governing-text block this document itself reproduces (Section 2.1, Section 2.2) and should not be presented as a quotation from "Part Eight's own governing text." This changes the *sourcing basis* for the RS-3 result.
2. **Correct Open Item 9's overclaim of test coverage.** It currently asserts that "frame-break durability under repeated pressure" and "the construction-time-versus-runtime cross-world-isolation distinction" were "addressed at the illustrative level... in Sections 3.8, 4, 3.7" — neither was, and Open Item 8 (in the same document) correctly says cross-world isolation "this solo-world pass cannot test at all." This is a *scope-boundary* misstatement and should be rewritten to match what was actually tested, or a genuine repeated-frame-break-attempt probe should be added to Section 3.4/3.8.
3. **Fix the tally arithmetic** in Section 5 and the closing summary: the correct PROVISIONAL count is 10 (not eleven), and the correct SECOND LOOK count is 8–9 (not eleven).
4. **Fix the internal cross-reference errors**: AN-2's pointer to "Section 3.8" should point to Section 4; SF-1's claimed Open Items flag ("adjacent to the Claim-Laundering judgment-call concern") should either be added to Section 6 or removed from SF-1's own text.
5. **Correct the SE-2 misquote** ("thin" should be "small," per Formation Calibration §2.3's and Doc_02 §11's actual wording).

Recommended but not strictly required for a "substantial" bar: reconsider SR-3's unqualified PASS in light of the same VI-4-adjacency reasoning applied to CT-3; add or explicitly flag as still-missing a probe testing the temporal-horizon default (399/410-as-recent-news) under Engagement Architecture §8's own instruction.

None of these findings undermine the document's core design or its Persian-anchor/firewall/C4 discipline, which are sound. But a document whose stated purpose is rigorous, honest self-scoring should not itself contain a fabricated citation, a self-contradicting Open Items section, and miscounted tallies — these are exactly the kind of defects this project's own review discipline exists to catch before sign-off.
