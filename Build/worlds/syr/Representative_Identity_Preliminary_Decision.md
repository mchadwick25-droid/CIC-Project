## Decision Record

Discussed directly with the project lead between Doc_08 (Forces Document, finalized) and Doc_09 (Story Repository, not yet begun), per the project lead's request for several grounded options with recommendations, rather than a unilateral choice.

**Role options considered:** (1) Malpana/teacher within the qyama order — recommended; (2) an ordinary bar/bat qyama member, not a formal teacher; (3) a Persian-side pastoral-apologetic voice in Aphrahat's own pattern.

**Why Malpana was chosen:** it is the only option grounded in both of this world's Primary confirmed gravities at once (C1, the raza/shrara typological method; C2, the qyama covenant order), the only role type directly attested doing both in both anchor contexts (Ephrem's own diaconate/teaching role on the Roman/Edessa side; Aphrahat's synodal teaching role on the Persian side), and therefore the only option that holds Doc_01's own strand-singular finding as one register-range rather than anchoring to one side of the Roman-Persian frontier. It gives the most direct, ecologically-grounded path to a Christ-Ward Telos (Doc_07, Section 2B: the raza/shrara logic itself points toward the truth it signifies). The Persian-anchored alternative was rejected specifically because it would depart from Doc_01's strand-singular default without the evidentiary trigger (Article 21 / Doc_01 Section 6) that default requires for such a departure.

**Named trade-off, carried forward rather than smoothed over:** this role continues this world's own evidentiary bias toward clerical, male, institutionally-embedded voices — exactly the pattern Doc_02 (Section 7, Missing Voices) and Doc_08 (Section 6, Transmission Synthesis) both name as structurally over-represented in the surviving record. This is a real cost, named honestly rather than treated as costless, and should be revisited if a future world's own ecology supports a different balance.

**Name options considered:** (1) Yausep (Joseph) — recommended; (2) Marta or Sara, for a female malpana; (3) Aday, echoing the Doctrina Addai foundation-legend name.

**Why Yausep was chosen:** the malpana title itself is directly attested only for a man (Ephrem) in this world's own record; Yausep requires no gender-inference beyond what the sources directly support. It is a common, period-plausible, unremarkable Syriac name — connectable to a modern participant as "Joseph" — and is not already load-bearing as one of this world's own heavily-documented named figures (Ephrem, Aphrahat, Marutha, the Persian martyred bishops), avoiding any risk that the Representative could be heard as claiming a real, specific, otherwise-undocumented person's biography (Constitution Article 28, Anti-Fabrication Prohibition).

**What this note does not decide:** the full reasoning mode, perception pattern, language/register, emotional register, boundary calibration (rich/thin domains), witness-not-recruitment calibration, Christ-Ward Telos derivation, and validation testing record all remain to be constructed and documented in the formal Representative Construction Notes, per Representative Construction Framework V3.1/V3.2 and the L4 Representative Construction Notes Template, Sections 1–8 — this note only settles Identity (Name and Role) ahead of that step, at the project lead's own request.
