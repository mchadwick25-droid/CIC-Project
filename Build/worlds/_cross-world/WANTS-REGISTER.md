## Adding to this register

It is generated, not maintained: a source becomes a want by being written as a `source` record with no vendored edition, which is what a build thread does anyway when it consults something it cannot vendor. Nothing extra to remember.

A source that is *wanted but not yet consulted by any world* has no record and so will not appear here. If the corpus-assignment thread finds such things — and it will, working through a collection this size — they belong in the same place: a `source` record with `edition: "not vendored"` and a `discovery_channel` saying where it was seen. It then shows up with value 0, which is honest: nothing depends on it yet.
