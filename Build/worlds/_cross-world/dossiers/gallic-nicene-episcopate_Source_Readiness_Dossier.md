## 4. Checked and closed

| candidate | why it looked promising | why it's closed |
|---|---|---|
| Hilary's Commentary on Matthew | Substantial surviving work, never in NPNF | Never translated in the PD era at all; only translation is D.H. Williams, CUA Press *Fathers of the Church* vol. 125 (2012) — confirmed access-restricted/controlled lending on archive.org, i.e. in copyright |
| Full *Tractatus super Psalmos* (~58 psalms survive) | Only 3 "specimens" translated in NPNF — the rest might exist elsewhere | Checked against the original 1898/99 NPNF2-09 print volume itself (`StHilaryOfPoitiersSelectWorks`) — the 19th-c. translators only ever rendered 3 specimens; no PD translation of the rest exists |
| Ad/Contra Constantium | Real polemical work from this window | Only modern, copyrighted translations exist (Wickham 1997, Flower 2016) |
| De Mysteriis + hymn fragments | Would add liturgical/hymnic material | Only a Latin critical edition (Gamurrini 1887); no English translation of any kind found |
| Phoebadius of Agen, *Contra Arianos* (c. 357–8) | The one other surviving anti-Homoian Latin polemic from this exact window | Only full English translation is a 2008 University of Florida independent-study project, self-hosted on fourthcentury.com — could not verify a license statement (domain blocked by this session's egress proxy) and found none via search. **Not a confirmed rights-cleared text — do not queue without direct rights confirmation.** |
| Eusebius of Vercelli | A named contemporary bishop | Only ~3 short letters survive (Migne PL 12/10); no English translation, PD or otherwise, located anywhere |
| Reticius/Rhaetius of Autun | Another named contemporary bishop | No surviving text at all, only secondhand fragments in Jerome/Augustine; also predates the window (fl. c. 310–334) |
| Gregory of Elvira | Sometimes grouped with this circle | Spanish, not Gallic — wrong region regardless of translation status |
