# Gapped/diachronic formation-types — a standing precedent, drawn from LPC's own build

**Status:** Advisory precedent, written up 2026-09-15 from Latin Pastoral-Congregational
Christianity's (LPC, Atlas I.8, world file-code `lpc`) own build experience, at Mark's
request, for him to hand directly to a build thread facing this shape of problem.
**Not a Constitution amendment and not a ruling that closes the open question below** —
this project's source-research thread has no authority to do either. It is a
distillation of what actually worked and what actually failed, the first time this
project's own governing documents' real, named gap was hit in practice, offered so the
next gapped world doesn't re-litigate it from zero.

## 1. The open question this document does not close

The portfolio-level Step 0 Conclusion (`CiC_Step0_Conclusion_FINAL_v2.docx`) logged this
directly, quoted verbatim, under "Constitutional ambiguity flagged, not resolved":

> Article 3 (Formation-World Principle) requires "sufficient historical coherence" but
> does not define whether a formation-type may recur across a temporal gap with a rival
> claimant contesting the interval (Cyprian/Augustine, with Donatism in between), or
> whether it requires continuous, unbroken community existence. Checked directly against
> the Constitution's actual text and found genuinely undefined. Logged as a standing
> interpretive question, likely to recur.

Its own decision list records the same item as: *"Constitutional ambiguity on
gapped/diachronic formation-types logged, not resolved."* LPC is that pairing's own
first real test case — not a defect LPC introduced, a pre-existing gap in the
Constitution's own text that LPC's build was the first to actually stand inside.

## 2. What a "gapped" formation-type actually is

Not every world with a wide time window has this problem. LPC's specific shape:
two anchor figures (Cyprian, 248–258; Augustine, 391–430) separated by 133 years —
most of the world's own 246–430 span — with **no surviving voice native to this
world's own boundary** for the interval between them. That interval is not
undocumented history in general: the Great Persecution, the *traditio* crisis, and
the rise of Donatism are all richly attested for exactly those decades — but
overwhelmingly through sources that belong to a neighboring built world (Donatism,
I.4), not to this one. Doc_01 named this precisely, and the phrasing is worth reusing
verbatim in any future world with the same shape: *"an honest silence in this world's
own record, not a general absence of evidence about the period."*

A gapped world is not automatically constitutionally coherent, and not automatically
broken. Section 3 below is how to actually tell which.

## 3. What held the world together — the pattern that worked

Doc_01 §5 found LPC strand-singular (one movement, not two) on evidence that **does not
need the gap bridged at all**: formation emphasis (ordinary pastoral care, preaching,
catechesis, penitential discipline, sacramental administration) and ecological
orientation are each demonstrated independently, on their own terms, in *both* the
Cyprian phase and the Augustine phase. Neither claim depends on anything happening in
between — they are two separate, self-standing demonstrations of the same recurring
pattern, not one thread stretched across 133 years of silence.

Doc_04 then formalized this as the actual gravity-discovery discipline for a
strand-singular, gapped world: **phase testing substitutes for cross-strand testing.**
With no strands to test across, every candidate gravity is instead tested
independently across the Cyprian and Augustine phases — the Persistence test at each
candidate's own entry, cross-referenced against a phase-bound flag. A gravity visible
in only one phase is flagged phase-bound and excluded from the world's own core
argument, exactly the discipline cross-strand testing exists to enforce elsewhere.

**The generalizable rule:** a gapped world's own coherence argument should rest on
whichever candidate gravities are independently well-attested on *both* sides of the
gap, each on its own evidentiary footing — never on a single thread asserted to run
continuously through the silence itself. If the world's coherence argument only works
by treating the gap as bridged, that is the signal the world may not actually be one
formation-type — not a sourcing problem to solve by finding better evidence for the
bridge.

## 4. What went wrong, and why — the pattern to not repeat

One candidate gravity did structurally need the gap bridged: conciliar authority (how
a bishop relates to other sees) — Doc_01 itself flagged it in advance as "weakest on
the conciliar-authority axis." It has exactly one attested locus in each phase, a
century apart. Doc_04's own finding on it is precise and worth quoting as the honest
target outcome: **"thin across the span, not bounded within it"** — real, but not
persistent at world level. That is not an unfinished analysis. It is the correct,
final shape of what the evidence supports.

It was not treated that way at first. Two failure modes compounded:

**4a. Reaching for a neighboring world's own evidence to bridge the gap.** Because the
one plausible large source touching conciliar authority near the gap period is the 411
Conference of Carthage's own *Gesta* (Acts) — a dense, two-column transcript inside
`cic/texts/pl11-zeno-optatus-collatio-carthaginiensis_migne.txt` (the ~145,000-line
Migne PL 11 volume it sits within), native to Donatism's own world, not LPC's — the build
repeatedly reached for it hoping it would shore up the thin candidate. Two independent
attempts to extract usable findings from it were both found unsound on review: the
first read counted Migne's editorial apparatus as conference record and its own key
term count came in roughly 45% low; the second mistook a genuine ~7,000-line band
(lines 118500–125499, which in fact holds 40 numbered act headers, 138 subscription
formulae, and 401 `episcop-` tokens) for footnote apparatus without ever opening it,
and misattributed a speaker across a two-column line split. Neither failure was
carelessness in a lazy sense — a source this dense, under real pressure to
make it say more than it safely supports, produces exactly this kind of confident,
wrong read. **The lesson is not "read more carefully." It is: a source that belongs to
a neighboring world's own home territory should be used for narrow, specific,
independently-verifiable facts only (LPC's own surviving example: confirming act 158
is Augustine's own subscription, not a debate speech) — never asked to retroactively
prove a thin candidate's persistence across a century it was never written to
document.**

**4b. Treating "thin, Supporting" as an unsolved problem rather than the answer.** The
candidate's own classification was superseded five separate times across nine review
rounds — each new attempt finding a subtly different, technically plausible way to
read the Framework's own test language so the candidate would pass more cleanly than
its actual evidence supports (a miscounted clause, an ellipsis that inverted a
sentence's meaning, a misapplied "ambiguous results" provision). Mark had to rule it
directly (Supporting) to stop the cycle. **The lesson: when a candidate's
own Persistence result is genuinely bimodal — real in both phases, but at one locus
each, with nothing in between — "Supporting, and honestly thin" is very likely the
correct and final classification, not a puzzle with a cleaner answer waiting to be
found. Treat five consecutive re-classifications of the same candidate as itself a
signal to stop and accept the narrower finding, not as five steps of legitimate
progress toward a stronger one.**

## 5. A working checklist for the next gapped world

1. Name the gap exactly as LPC's Doc_01 did: an honest silence in *this* world's own
   record, distinguished explicitly from whatever rich evidence survives for the same
   interval in a neighboring world's own territory.
2. Build the strand-singularity / world-coherence argument only from candidates
   independently attested on both sides of the gap — not from anything that needs the
   silence itself bridged.
3. Where cross-strand testing would normally apply, substitute phase testing: test
   every candidate gravity separately in each phase, flag anything visible in only one
   phase as phase-bound, and exclude it from the coherence argument.
4. If a candidate's own Persistence result comes back thin-but-real — attested at only
   one or two loci across the gap, not continuously — classify it Supporting (or
   whatever the Framework's own tests actually return) and stop there. Don't reach for
   a neighboring world's own home-territory sources to bridge it; use them only for
   narrow, independently-checkable facts if at all.
5. If, after step 4, *no* candidate can carry the coherence argument without the gap
   itself being treated as bridged, that is a real finding — flag it as a possible
   Article 3 boundary case and escalate to Mark directly, rather than resolving it
   quietly. The portfolio Step 0 Conclusion's own unresolved question (§1 above) is
   exactly what that escalation would be testing.

## 6. What this document is not

It does not answer whether a formation-type may, as a matter of constitutional
principle, recur across *any* gap with *any* rival claimant in the interval — that
question is still open, on record, at the portfolio level. This document only records
what actually worked for one real case (LPC) once a project-lead ruling closed its own
open loop, so the next build facing the same shape starts from that experience instead
of from zero.
