**G1. Cyprian, critical Latin edition — Wilhelm (Guilelmus) von Hartel (ed.), *S. Thasci Caecili Cypriani opera omnia*, Corpus Scriptorum Ecclesiasticorum Latinorum (CSEL) 3.1–3.3 (Vienna: C. ## 3. Consultation-only secondary scholarship, editions, and reference works (never vendored)

This heading's own "secondary scholarship" phrase is a loose label, not the Registry's own Type field — rows in this category span Types P, P/S, M, and L as well as S, and the rule below is what actually governs membership, not a shared Type. All the works this category reaches share the operational fact that matters to this heading — in copyright, never vendored, no acquisition decision needed — regardless of which Registry Type each one carries.
