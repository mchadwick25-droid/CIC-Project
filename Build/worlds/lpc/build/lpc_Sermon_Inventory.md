# lpc Sermon Inventory

This file lists the 97 Augustine sermons in the NPNF translation "Sermons on Selected Lessons of the New Testament" (`cic/texts/npnf106_augustine-sermon-mount-harmony-gospels-homilies.xml`, div1 `vii`), NPNF 1 to 97, which are Maurist sermons 51 to 147. For each sermon it gives the start line in two Latin witnesses. The first is Migne PL 38 (`cic/texts/augustine_sermones-1-340-lat_migne-pl38.txt`). The second is the Gaume-Migne volume 5 (`cic/texts/augustine_sermones-ad-populum-lat_migne-gaume1841-t5.txt`), first part only (before line 124000; the later part holds the doubtful sermons, which use different numbers). Both are noisy OCR. A start line is the line of the "SERMO" heading. A start line is confirmed only when the Latin title lines that follow it name the same Gospel book as the NPNF title, and either the same chapter or the same quoted words or episode. Where the chapter numeral is damaged by OCR, the row says yes only if the quoted words or episode agree, and the note gives the numeral as read. A readable difference in chapter is marked no. Where the title lines cannot be matched, the cell says unconfirmed with the reason. Headings are copied with runs of spaces reduced to one. "Line" means line number in the vendored file.
