## Findings — Low Severity

### L1. Residual looseness in §6's Circumcellion/*agonistici* Open Item partially re-blends existence and self-designation

Doc_03 §0, the Agonistici roster row's own AG-risk cell, §2, and §4 all now state the existence/self-designation distinction Round 1's M2 asked for correctly and identically: the group's bare *existence* is independently attested via imperial legislation (CTh 16.5.52, unvendored); the specific word *agonistici* (the group's own *self-designation*) reaches this record only through Augustine's report of it. This was checked in all four locations this session, not assumed from Round 1's account, and all four are consistent with each other and with Doc_02 §6's own underlying account.

One further sentence, in §6 Handoff and Open Items, was not part of Round 1's specifically-named checklist (§0/roster/§2/§4) but is still part of the document and still touches the same term:

> "Open item (Circumcellion/agonistici, Cluster 5): CTh 16.5.52 itself, the specific law naming the group, remains unvendored after five acquisition attempts (Doc_02 §1); **this entry's existence-and-self-designation claims rest on Doc_02 §6's own account of Augustine's report**, not on independent access to the imperial law itself."

Read plainly, this says both the existence claim *and* the self-designation claim rest on "Doc_02 §6's own account of Augustine's report." That is not accurate for the existence half: per Doc_02 §6 itself, the group's existence rests on imperial legislation naming them (a claim Doc_02 §6 reports from field/scholarly knowledge that the law exists, not from Augustine), while only the self-designation claim specifically rests on Augustine's own report. The sentence's likely intended point — that this document has no *independent, this-session* access to the primary CTh text for either claim, so both currently rest on secondary description — is defensible, but as worded it re-collapses the same two-claims-under-one-label pattern M2 was raised to fix, in the one place this document was not specifically asked to re-check.

**Disposition:** Low, not Medium, because every place this distinction is actually operative for a downstream reader — the AG-risk cell Doc_04 would consult, the §2 instruction Doc_04 is told to keep active, and the §4 contest description — states it correctly; this is a single loosely-worded aside inside a section whose whole purpose is to flag things as still-open and not yet resolved, not a declarative claim a builder would rely on directly. A one-clause tightening (e.g., "...rest on Doc_02 §6's own account — existence via the [unvendored] imperial legislation it reports, self-designation via Augustine's own report — not on independent access to the imperial law itself") would remove the ambiguity. Optional at the reviser's discretion; does not block disposition.
