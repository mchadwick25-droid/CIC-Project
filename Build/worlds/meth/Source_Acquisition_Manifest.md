## Cross-world queue seeding

Per `CLAUDE.md`'s "Scaling the build" discipline and the cross-world source layer in `Build/reference/method/CiC_Record_Native_World_Build_Process_V2.0.md`, only **G1** (the Wesley Journal volumes II to VIII, four of them individually host-verified) is added as a candidate row to `Build/worlds/_cross-world/download-queue-seed.yaml`. G2, G3 and G5 are plausible leads (a Gutenberg volume-number search for G2; specific archive.org identifiers not individually checked for G3; no dedicated search run for G5) but none is host-verified to the standard that file requires before a row is added, so they are listed here as leads that are not added to the queue. G4 and G6–G10 are left off the shared queue for the same reason: each requires either a different acquisition channel (G4) or a dedicated search that has not been run (G6–G10).
