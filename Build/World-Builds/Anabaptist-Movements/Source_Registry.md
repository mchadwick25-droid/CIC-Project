# Source Registry: The Anabaptist Movements

Per `Source_Registry_Template.md` V1.0. Co-equal Step 2 output with `Doc_02_Source_Ecology.md`. **Living document: append-only.** A row is never renumbered or deleted. Doc_02 may not name a source in support of a specific claim unless that source has a row here. Rows are entered for works the corpus map assigns to this world, for the dossier's cross-links, leads and closed items, for works the census names, and for finds of the field-bibliography sweep. A vendored work assigned only to another world has a row only where the dossier named it, and that row licenses nothing. Other such works are listed as candidates in `Open_Gaps_Tracking.md`.

**Status:** Revision 2, issued with Doc_02 Revision 2, which is Approved to proceed (Round 2 Cleared). Living document, append-only. Not Frozen.
**Boundary checked against:** `Doc_01_World_Identification_Boundaries_Orientation.md` (Revision 3, Approved to proceed): 1525 to 1650; the Swiss lands, Moravia and the Netherlands; two Article 21 strands (a Congregational strand across the Swiss and Dutch wings, and a Communal-Property strand in Moravia). The world has no registry code yet. Boundary Status is judged by what a source speaks for, never by the publication date of a modern edition. Münster is outside the scope (Doc_01 §1, §7 item 5), so Münster sources are Excluded.

**Type:** P (Primary) / S (Secondary) / M (Material/External) / L (Period Lexicon).
**Confidence (citation reliability):** A = the Licensed-For passages were read and matched in the vendored file by a structure marker (a heading, an article number, a document number, a printed page number or the edition's own title). B = a specific work or locus is named and exists in the vendored file (or, for a work not vendored, the host record was read), but the Licensed-For content was not itself re-read. C = a real author and work, no locus checked, not vendored. D = a body or genre of material, no single text named. No row is E.
**Structure markers:** line numbers are lines of the vendored file in `cic/texts/`. Where an edition has its own divisions (Funk's running heads and page numbers, Dordrecht articles, Egli document numbers, Beck's page numbers, Vedder's pages) the row gives them as well.
**Quotation rule:** quotations in this Registry and in Doc_02 are matched to the vendored files after whitespace and line-break hyphens are normalised and the long s is read as s. No other letter is corrected, so the scans' OCR errors stay in any quotation. No page image was available to this pass, so every German quotation is checked against the scan text only.
**Quotability flag (per file and per row):** *verbatim-ready* means the scan reads cleanly enough to quote; *verbatim-ready after page-image check* means the same, with the file header's rule that each passage be read on the page image before it is used; *second witness only* means the scan is garbled and nothing may be quoted from it (Library ruling, `LIBRARY-DECISION-LOG.md`, point 5); *unusable* marks a part of a file with no readable text.
**Voice flag:** own voice, opponent voice, coerced own voice recorded by the authorities, or mixed. A work that mixes voices says where.
**Rights:** each vendored row relies on the file's own header. For a lead not vendored, the row gives the host's copyright-status field as read on 23 October and no more. The Library must verify rights before any acquisition.
**Holdings:** the holdings report (`python -m engine.m9.cli holdings <code>`) needs a registry code and a time window, and this world has neither. Every file of the corpus-map bucket has a row. The shelf search in Doc_02 §9 stands in for the report until the code exists (Open_Gaps).

**Not closed.** The Registry holds every source the builder could identify from five channels: the corpus map (26 rows, 25 files); the Source Readiness Dossier (sections 1 to 5); the census entry (`sources`, `voices`, `documentedStories`, `experienceToday`); a full-text search of the whole shelf; and the bibliographies, prefaces and footnotes inside the vendored books (Vedder's Bibliography, Böhmer's introduction, Beck's Vorrede, Funk's Publishers' Preface, McGlothlin's notes, Bossert's footnotes). It also holds the finds of a title and creator search on archive.org run on 23 October 2026 (38 queries: 27 first runs, four repeats in simpler form after a connection reset, and seven for the works named in the recall test).

**The shelf search.** The shelf holds 842 entries in `cic/texts/` (797 `.txt` files, 38 `.xml` files and 7 others). The pattern `anabapt|catabapt|wiedert[aä]ufer|wiedertoeuf|\bt[aä]ufer|menno\b|mennonit|hutterit|hutterisch|hubmaier|ausbund|\bamish`, case-insensitive, matches 167 files by two methods (a Python regular-expression scan of each file, and `grep -l` in the `C.UTF-8` locale). Twenty-five of those are this world's files. Of the other 142, the ones with the most hits are listed as candidates in `Open_Gaps_Tracking.md` and have no row here, because each is assigned only to other worlds.
