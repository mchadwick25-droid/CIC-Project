## OG-1. Cross-thread: the Society of Jesus Doc_01's own characterization of this world

**Status: OPEN, standing flag for periodic coach verification — not this thread's to fix.**

Doc_01 Revision 2 (§1, Distinctive Contribution) carried a cross-thread flag stating that
the Society of Jesus Doc_01 draft misdescribed this world as "a separate, already-built
world." `Doc_01_Review_Round2.md` finding N3 (2026-09-26) found that flag half stale: the
Society of Jesus Doc_01, independently reviewed and cleared to Revision 2 (`Approved to
proceed`, `Build/worlds/jes/Doc_01_World_Identification_Boundaries_Orientation.md`,
§1, l. 26), now reads "a separate world in this project's portfolio, currently at the same
Doc_01 [drafting stage]" — no longer "already-built." The review judged that a standing
flag about another thread's own draft will go stale in the same way again if it is left
inline in a canonical document, and directed that it be moved here rather than repeated in
Doc_01 Revision 3.

**What is still live, and what is not.** The "already-built" misdescription is resolved and
not carried forward. The Jesuit Doc_01's characterization of this world's own core identity
as "withdrawal into disciplined domestic devotion" (same document, same section) is **not**
corrected by the Jesuit thread's own Revision 2, and remains inaccurate on this world's own
terms: this world's Core Identity (Doc_01 §1) is a household movement staying inside
ordinary town life, not a movement organized around withdrawal from it — a real, substantive
distinction this world's own Doc_01 already draws for other purposes (Section 3's contrast
with Desert Monasticism turns on exactly this same withdrawal-versus-town-life axis). This is
a defect in the Jesuit thread's own document, not this thread's to correct directly, per this
build's own discipline against touching another thread's content — named here so it is not
lost, for that thread (or a coach pass) to fix.

**Action required:** the Society of Jesus build thread (or a coach verification pass) should
correct "withdrawal into disciplined domestic devotion" in its own Doc_01 to something
consistent with this world's actual Core Identity (a lay household movement inside ordinary
town life). This entry should be checked again whenever either world's Doc_01 next revises,
since a standing cross-thread characterization is exactly the kind of claim that goes stale
quietly if nothing outside either document tracks it.
