# Usage discipline — Mark's own account settings

The cost rules threads follow live in `CLAUDE.md` (2.2 models, 2.3 budget, 3.2 spending, 3.3 context). This page holds only the account-level settings Mark manages himself, which moved out of `CLAUDE.md` on 2026-10-19.

## The plan

- The account is on Max-200. $200 a month is a real financial stretch, not a comfortable ceiling with room to spend past. Treat it as a hard cap: get everything possible from the flat fee, never fall back on paid overage.
- Max-200 draws Claude chat, Claude Code, and Cowork from one shared usage pool. When more than one surface is in use, watch the total burn across all of them, not just one session.

## Settings to keep

- Keep "extra usage" OFF in Settings → Usage, or capped at $0. Hitting the weekly ceiling is a signal to spend less, not a cue to let paid overage kick in. Don't leave it on "just in case."
- If overage is ever needed for something genuinely unavoidable, turn it on deliberately, do the one thing, and turn it back off.
- A session's own cost telemetry (what the work would have cost at raw API rates) is not a bill by itself. Only actual overage usage is.

## Checking

- Check `/usage` periodically to catch a runaway pattern before it costs the rest of the week.
