# ce_aa: The Christian East, eight numbers 1920-1922

DL file names: `per_christian-east_the-christian-east_<YYYY-MM>_<vol>_<no>__..._djvu.txt`. Lines are `grep -n`/`sed -n` line numbers.

## Findings common to all eight files (items 1, 8, 9)
- Item 9: no hits for digitized/google/archive.org/microfilm/copyright/all rights/permission in any file. "reproduc" hits are body text only. No library slip, microfilm target or advertisement leaf at the top of any file.
- Publisher line: found only in 1921-04 (see below). The other seven files carry no "Published by / Printed / Press / Ltd" masthead line (greps run on each). The only press names are in reviews or footnotes (Mowbray, Dent, Clarendon Press, Faith Press, Patriarchal Press Constantinople).
- Every file opens straight on the number-line, then the title "The Christian East", then the first item. There is no contents leaf in any file.
- Item 8, year later than file year: only 1920-12 (line 3933, "Friday, March 17th, 1921", an in-memoriam leaf). 1921-12 mentions "1921" only for the same year. No later years found in the others.
- Item 6 OCR, all files: English text is mostly readable, with scattered garbles in headings and drop-caps ("HE" for "THE"), stray punctuation, and runs of junk lines from plate leaves. Page footers, running heads and footnotes run into the text. Polytonic Greek is garbled to Latin lookalikes. Hymn pages (1921-09, 1921-12, 1922-03) are heavily garbled. French (1921-12) is clean apart from accents.
