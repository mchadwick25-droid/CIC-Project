# Card edits: Novatian

Existing card kept word for word. Every edit below is an addition. No existing statement was found wrong, so nothing was corrected. File short names: ANF = anf05 (Novatian, Cyprian), EP = Hartel's Cyprian (Latin), EUS = npnf201 (Eusebius, McGiffert), SOC = npnf202 (Socrates, Sozomen), ANF6 = anf06 (Dionysius, Salmond), NIC = npnf214, JER = npnf203, AMB = npnf210, HARN = Harnack, Chronologie II.

## quotationOriginals (four entries, one per quoted span in the brief; all awaiting second reading)

1. Old: none. New: "Let them knock at the doors, by all means, but certainly not break them down." Printed: ANF 31758-31759 ("Let them indeed knock at the doors, but assuredly let them not break them down"). Original (clean TEI, kept): EP 4222 ("pulsent sane fores, sed non utique confringant.").
2. Old: none. New: Dionysius, two sentences. Printed: McGiffert, EUS 38923-38925. English alone, since the only held Greek (Schwartz) is a damaged scan ("axzov", "Exam"). Greek read by hand. Note credits Salmond's different wording (ANF6 9905-9925), the Novatus/Novatianus naming (Salmond's note), and the Rufinus confirmation.
3. Old: none. New: "the pure". Printed "pure" and original καθαροί, both in McGiffert's note, EUS 38270. Greek checked by hand.
4. Old: none. New: "Set up a ladder, Acesius, and climb to heaven alone." Printed: Zenos, SOC 3720-3721. English alone, since the Greek (SOCG 9912-9913) is damaged scan OCR. Note credits Sozomen's wording (SOC 28087) and gives the Greek the modern wording follows, read by hand.

10. Martyrdom: McGiffert (EUS 38240-38242), Harnack (HARN 22550-22554), Coxe (ANF 60394-60397). Adds to the existing Valesius entry, which is unchanged.
11. Acesius's see and the ladder's meaning: Socrates (SOC 3685-3721), Sozomen (SOC 28080-28090, 30570-30572).
12. How long the church lasted: McGiffert (EUS 38242-38244; already on the card), Ambrose's editor (AMB 33379-33381).
