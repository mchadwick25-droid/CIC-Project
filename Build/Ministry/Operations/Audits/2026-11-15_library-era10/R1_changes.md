# R1 changes: Library era 10, batch 1, 2026-11-15

What the Library thread changed in answer to `R1_review.md`. The first vendoring was undone and the batch was vendored
again from corrected specs, so no file carries a patch on a patch. One line number (Spinka's omission mark) was
corrected by hand afterward, in the header and the registry note.
