## Findings

1. Correction. Acta Sanctorum: the file carries two years. The engraved title (file line 189) reads 1868; the
   letterpress title page (line 226) reads 1867. The records gave only 1868. Record both.
2. Correction. MGH Scriptores II: the Vita Rimberti row had `author: rimbert`. Rimbert is the subject; the editor's
   preface says another wrote it, a cleric of Bremen or a monk of Corvey. Use an anonymous author slug with a ruling.
3. Correction. Mendham: the introduction does not start at OCR line 144, which is the list of corrections; it
   starts at file line 511.
4. Correction. Mendham: Session II's heading is at file line 8261; 8402 is a running head.
5. Correction. Arendzen: the uploader's cover sheet runs over OCR lines 1-24, not 1-11; the title page starts at
   OCR 28.
6. Correction. Arendzen: a second Addenda heading stands at file line 3752; the Arabic begins at about file 3791.
7. Correction. Mendham: the scan opens with Google's sheet, which asks for non-commercial use of the files. It
   is a request on a public-domain book, not a licence; the header and the search log should say it is there.
8. Note. MGH Scriptores II: the Vita Anskarii heading is at file line 57637 and its text at 58036; the stated
   line fell on a running head.
9. Note. Matthew of Edessa: the shelf rows said the preface was not read for a date, while the decision log placed
   him in Edessa in the twelfth century. The preface supports that (file line 853). Cite it.
10. Note. Search log: 'Five more records' lists four.
11. Note. Spelling: 'licence' in the search log; the intake rules use the same form.
