# Ignatius of Antioch: calibration brief 1 of 6

The first of the six calibration briefs (Decision-Log, "The story process", 2026-11-16). It follows the process approved to proceed with the Polycarp benchmark (`../2026-11-16_polycarp-clean-write/`):
1. A researcher builds the source sheet.
2. A second Opus renders the quotes blind, and a third compares the two renderings.
3. A fresh writer works from only the standard and the writer's sheet.
4. An Opus reviewer reads it.
The standard is `../2026-11-16_polycarp-clean-write/Standard_draft.md`.

Only Mark and the reviewer see the published lives gathered for comparison. The writer never does.
