# CP.9 cross-world re-test: frozen settings, written before any run (2026-11-02)

- Engine code: the anonymous-label branch at commit 0ba8281587d0bb643b8eaeab2eb74068e69be16d (main 292e4635 plus the anonymous-work label). The run uses that commit's engine; nothing is edited between the first draft and the last rating.
- Worlds: lpc, alx, syr, rzg. Questions: the 28 sealed probes (q001 to q028), same wording as the cross-world baseline, read by probe id. No tuning on them; no record, sidecar or seed edited for a named question.
- Arms, per world, one run each. A: the old engine's saved answers (gate-replay sentences with removed=false, as in the baseline). B: the current engine without the passage offer. C: the current engine with the passage offer. B and C use the same sidecar (lpc's with the C5 splits), the same reader and safety replies, the same joining sentences and the same helper roster. Reader and safety replies for alx, syr and rzg are the baseline's saved replies; lpc's reader is run again because its catalogue now holds the split ids.
- Offer: the passage offer built from each world's seed file on main at 292e4635 against the index named in the seed (lpc b7511f92, alx 96384507, syr 45478e0c, rzg c6b31db1). Lens rule: a seed offered only when its shelf_binding starts "row narrowed". Budget: 6 passages and 1800 words per sub-question, in the seed's reviewed rank. Offered counts: lpc 102 passages over 52 sub-questions; rzg 50 over 31; alx 0; syr 0 (alx and syr are the no-passage controls).
- Helpers stand in for every model call (reader, safety, voice, read, rewrite, re-read). No metered spend.
- Rating: one Opus reader per world, blind, A, B and C answers to the 28 questions in random order, shuffle seed 20261102 (written here before the draw), one rubric: answers the question (yes, partly, no); depth (rich, adequate, thin, flat); plain to hear (yes/no); speaks as the community (yes/no) where it should; accuracy: ok, tier 3 (craft), tier 2 (scope or ecology: a claim a scholar would call unsupported or too wide for the world's shelf), tier 1 (false or invented). Separately: for each question, whether a fitting record or passage was in the offer.
- Strata, reported for every metric within the same questions and for the whole set: sub-question seeded with offered passages vs not seeded; and, apart, the questions whose reader-named sub-question is in C5 (so the split's effect and the offer's effect can be read apart). A world with fewer than 5 seeded sealed questions is reported "too few to read" and not averaged in.
- Success rule, stated before the run, applied per world: on the seeded stratum C answers the question "yes" in at least as many questions as B and moves depth toward A; accuracy tier 1 and tier 2 do not exceed B's; passage-bound sentences are supported at the rate of record-bound ones or better; the unseeded stratum shows no change beyond helper noise.
- Limits stated: one run per world, one reader, the old engine's writer differs from the helpers, small seeded strata.
