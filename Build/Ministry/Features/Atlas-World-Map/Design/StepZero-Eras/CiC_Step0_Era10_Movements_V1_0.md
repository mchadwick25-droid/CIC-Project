## 0. What governs this re-test

- **The four marks** (change order, 2026-11-08, "a defined movement, not just a trend"): a
  recognizable beginning; identifiable carriers; a name or self-understanding as a movement; and
  recognition as a movement by historians.
- **The evidence rule for recent movements** (change order, 2026-11-08, "Change order: evidence
  for recent movements"; Mark: "we have to be able to tell an accurate story, but use different
  criteria"). The movement's own dated founding texts show marks 1–3. A standard scholarly
  reference work or academic study shows mark 4. Both are required for a "defined movement"
  verdict. Neither needs to be vendored in the Library.
- **Verification.** "Verified" means the item's bibliographic details (or a founding text's date
  and publisher) were confirmed in this run against a search result or page whose address is
  recorded. Everything else is [S], and [S] never counts as verified.
- **Window and living mark.** Era 10 runs 1906 to c. 2010; nothing after 2010 is claimed in the
  history. The living mark means alive today, graded CD or CR on its newest dated evidence.
- **How it was made.** Three Opus researchers, one per group below, each with web search and its
  own scratch space. No metered model calls.
