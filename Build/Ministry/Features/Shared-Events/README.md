# Shared Events — workstream

**Charter (Mark, 2026-10-17):** tell the councils, gatherings and confessions that
involved or changed more than one tradition. Each is its own story on the Atlas, outside
any one tradition, held to the same rigor, sources and craft as every tradition build.

**Status:** Exploring and sourcing. Nothing is built. The event list is agreed; the
sources are being found first.

## What is in this folder

- **`Decision-Log.md`**: append-only. One entry per ruling.
- **`Candidates.md`**: the 77 candidate events, by era, with the census movements each
  touches, the built traditions that draw on it, the vendored sources found by sampling,
  narrated episodes in those sources, known legends, and download-queue rows. Source
  labels came from sampling, not full reading; each event is checked properly before it
  is built.

## Shape of an event story (proposed, see the decision log)

1. Why they met.
2. Who came, and who was missing.
3. What was argued.
4. What was decided, quoted from the source.
5. Who disagreed, and why, in each side's own terms.
6. What it left.
7. Stories from inside the event's own sources, each with a modern telling.
8. How each tradition remembers it, linking to the stories on their cards.

Legends with no source from the time are explained in a note, never told as true.
