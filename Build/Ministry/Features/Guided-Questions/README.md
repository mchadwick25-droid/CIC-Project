# Guided Questions

**What this is:** the "what do I ask them" curriculum and UI design — a set of
role-aligned questions a participant can draw on when they don't know what to ask a
Representative, plus the entry-point design for arriving at a conversation via a
question rather than a world first (`QuestionFirst_Entry`) and per-world coverage
cards.

**Current state:** Curriculum V1.0 (100 questions) is content-complete but has
**never faced a live model** — the curriculum's own text says so. `Drafts-Archive/`
holds the two `Sets_V0_1`/`V0_2` files, which mark themselves "⚠ SUPERSEDED" in their
own text (the role × world matrix approach was cancelled) — kept for the record, not
live.

**Zero UI code exists anywhere in `cic-poc`** for this feature (confirmed by direct
search as of the 2026-07-17 readiness evaluation) — content and code-readiness are
each their own gate.

**Where deliverables land once integrated:** `cic-poc/frontend/` (new UI) and
`cic-poc/backend/` (curriculum content, likely as data the app serves).
